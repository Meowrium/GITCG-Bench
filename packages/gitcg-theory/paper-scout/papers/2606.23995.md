# EMAgnet: Parameter-Space EMA Regularization for Policy Gradient Self-Play in Large Games
- arXiv ID: 2606.23995
- Authors: Tristan Maidment, JB Lanier, Chase McDonald, Nathan Tsang, Eugene Vinitsky
- Date: 2026-06-22
- Relevance Score: ⭐⭐⭐⭐⭐

## Summary
EMAgnet improves policy gradient self-play training for imperfect-information games by replacing uniform regularization with an exponential moving average (EMA) of the last-iterate policy parameters. Rather than regularizing equally toward all actions (including dead/dominated ones), the EMA target adaptively tracks the agent's improving strategy, providing a more informative regularization signal. Evaluated on two-player zero-sum benchmarks including variants with exploration challenges and many dominated strategies.

## Key Contributions
- **EMA regularization target**: Replaces uniform prior with an EMA of policy parameters, providing adaptive regularization that evolves during training
- **Self-play for large imperfect-information games**: Policy gradient (PPO-based) self-play approach that matches/exceeds specialized game-theoretic algorithms
- **Dominated strategy handling**: Unlike uniform regularization (which wastes capacity on dead actions), EMA naturally prunes dominated strategies
- **Empirical validation**: Benchmarks with exploration challenges and large dominated strategy sets

## Connection to Our Work
- **Directly applicable to GI TCG self-play training**: Our MCTS+GBDT pipeline uses policy gradient methods; EMA regularization could improve convergence in GI TCG's massive action space
- **Action space efficiency**: GI TCG has many dominated actions (dead cards, irrelevant swaps); EMA-based regularization would naturally de-prioritize them
- **Adaptive prior vs. LLM deck prior**: EMA provides data-driven prior; could be combined with our LLM deck prior for hybrid regularization
- **Imperfect-information game focus**: Paper explicitly targets the same problem class (two-player zero-sum imperfect-info) as GI TCG

## Critical Assessment
**Strengths**: Elegant idea (EMA of parameters), direct application to card game self-play, well-motivated problem. Simple to implement.

**Weaknesses**: Short paper with limited experiments (only standard benchmarks). No code release mentioned. Single-domain evaluation (two-player zero-sum only).

**Reproducibility**: Moderate — algorithm is clearly described but no reference implementation. EMA tracking is straightforward to implement from scratch.
