# Distilling Game Code World Model Generation into Lightweight Large Language Models
- **arXiv ID**: 2605.24375
- **Authors**: Tyrone Serapio, Arjun Prakash, Haoyang Xu, Kevin Wang, Amy Greenwald
- **Date**: 2026-05-23
- **Relevance Score**: ⭐⭐⭐⭐

## Summary
Builds directly on Code World Models (CWM, 2510.04542 — our ⭐⭐⭐⭐⭐ paper from W22) by investigating whether the game world model generation capability can be distilled from frontier LLMs into smaller models. The authors introduce: (1) a curated dataset of 30 games spanning perfect and imperfect information, (2) a verification framework for generated code against structural and semantic game properties, and (3) a post-training pipeline combining Supervised Fine-Tuning (SFT) with Reinforcement Learning with Verifiable Rewards (RLVR). Using Qwen2.5-3B-Instruct, SFT improves syntactic correctness while RLVR improves execution-level adherence to game rules. The 3B model becomes capable of generating valid GameCWMs for both perfect and imperfect information games.

## Key Contributions
- First demonstration that CWM generation can be distilled into small (3B parameter) models
- Curated GameCWM dataset of 30 diverse games with verified implementations
- Verification framework that checks both structural properties (compile, execute) and semantic properties (rule adherence)
- SFT + RLVR pipeline specifically for game code generation quality
- Makes CWM approach accessible beyond frontier-model budgets

## Connection to Our Work
**Enables practical deployment of Code World Models for GI TCG.** Our W22 deep-dive on CWM identified the approach as our dream architecture (LLM generates executable GI TCG model → MCTS plans on it), but noted the reliance on frontier models (Gemini-level) as a deployment barrier. This paper directly addresses that:
- 3B parameter model is deployable on consumer hardware — crucial for GI TCG runtime
- The verification framework (structural + semantic checks) is exactly what we need to ensure the generated GI TCG model is correct
- SFT+RLVR pipeline provides a recipe we can follow: curate GI TCG rule data → SFT → RLVR for rule adherence
- The 30-game dataset methodology shows us how to construct GI TCG training data
- Authors are from Brown CS — credible but not DeepMind-level game AI group

## Critical Assessment
**Strengths:**
- Directly extends highest-relevance prior work (CWM)
- Practical 3B model makes approach deployable
- Verification framework addresses the "hallucinated game rules" problem
- Clear methodology for dataset construction and training

**Weaknesses:**
- Only 30 games — all relatively simple compared to GI TCG's complexity (elemental reactions, character abilities, equipment, dice system)
- No MCTS integration evaluation — only tests valid code generation, not whether models enable competitive play
- RLVR requires verifiable rewards — GI TCG rule correctness is complex to verify automatically
- No comparison of gameplay quality between frontier-model CWM and distilled CWM

**Reproducibility:** Reasonable — Qwen2.5-3B is open, pipeline described, dataset methodology clear
