# Orak: A Foundational Benchmark for Training and Evaluating LLM Agents on Diverse Video Games

- **arXiv ID**: [2506.03610](https://arxiv.org/abs/2506.03610)
- **Authors**: Dongmin Park et al. (NVIDIA + university collaborators)
- **Date**: 2025-06-04 (v3: 2026-04-14)
- **Categories**: cs.AI
- **PDF**: https://arxiv.org/pdf/2506.03610

---

## 核心内容

覆盖 **12 款流行视频游戏**，全品类（比 PTCG-Bench 只做一款游戏更广）。三大贡献：

1. **MCP 接口**: 基于 Model Context Protocol 的 plug-and-play 接口，支持不同 agent 模块在多样化游戏场景下的系统化研究
2. **Fine-tuning 数据集**: 专家 LLM gameplay trajectory，把通用 LLM 微调成游戏 agent
3. **三维评估**: 排行榜 + LLM 竞技场 + ablation 研究（输入模态、agent 策略、微调效果）

---

## 与 PTCG-Bench 对比

| | Orak | PTCG-Bench |
|---|---|---|
| 游戏数量 | 12 款全品类 | 1 款 (PTCG) |
| 深度 vs 广度 | 广覆盖 | 深度分析单一环境 |
| 接口 | MCP | 自定义 tool schema |
| 微调支持 | ✅ 提供训练数据 | ❌ 仅 eval |
| Self-evolution | ❌ 未强调 | ✅ 核心卖点 |
| Harness ablation | ❌ 未系统做 | ✅ H1/H2/H3 |
