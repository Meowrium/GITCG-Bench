## Summary

多轮多 agent LLM 游戏评测存在显著的 run-to-run 方差。长程交互中，早期的小偏差会跨回合复合放大。MEMO 是一个 self-play 框架，通过耦合 **Retention（持久记忆库）** 和 **Exploration（tournament 式 prompt 进化）** 来优化推理时的 context。Retention 从 self-play 轨迹中提取结构化 insight 存入记忆库，后续对局时作为 prior 注入。Exploration 用 TrueSkill 的不确定性选择跑 tournament 式 prompt 进化，用 prioritized replay 重访罕见和关键状态。在 5 个文字游戏上，GPT-4o-mini win rate 从 25.1% → 49.5%，Qwen-2.5-7B 从 20.9% → 44.3%，用了 2000 局 self-play。

## Key Contributions

- **Retention Bank**：从对局轨迹提取结构化 insight → 持久记忆 → 下局注入 context，作为 decision prior
- **Tournament Prompt Evolution**：TrueSkill 不确定性选择 + prioritized replay 重访关键状态
- **Run-to-run 方差下降**：Memory 不仅提升 win rate，更让排名稳定性显著提高
- 纯 inference-time 优化——不需要 fine-tune 模型权重

## Connection to Our Work

- **直接对接 DecisionFragment → Critic 管道**：当前 PlanV2 是静态开局生成，全局不变。MEMO 说的是「每局结束后 Critic 提取 3 条 key lessons → 存到 persistent memory → 下局开局注入 prompt」。这不需要改架构，只需 Critic 多输出一个字段。
- **strategy_store 已经做了持久化**：当前是人工写入 `p0_anchor` / `p1_anchor`。MEMO 的 retention bank 概念是「自动从对局经验中提取 insight」。可以从 Critic 的 `should_replan` + `suggested_adjustments` 字段自动提取。
- **Prioritized Replay**：我们的 self-play pipeline 目前没有区分关键状态和普通状态。MEMO 的 prioritized replay 可以用于选择哪些对局应该触发 Critic replan 分析。
- **Run-to-run 方差**：我们当前的 AI vs AI 评测没有报告方差。MEMO 提供了方法论——paired seeds + bootstrap CI 之外，还需要评估 prompt 变体导致的 policy 方差。

## Critical Assessment

**Strengths**: 纯 inference-time 优化，不微调模型；Retention + Exploration 双循环设计清晰；2000 局 self-play 证明效果；直接适用于任何 LLM agent 框架。  
**Weaknesses**: 2000 局 self-play 的成本不低（对 GI TCG 意味着什么？）；Retention bank 的内容质量依赖 extraction 逻辑；只在文字游戏上验证，卡牌 TCG 待确认。  
**Reproducibility**: 方法描述清晰，记忆库的结构化 schema 可参考设计。
