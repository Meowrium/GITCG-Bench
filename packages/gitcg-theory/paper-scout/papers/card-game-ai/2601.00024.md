# Quantitative Rule-Based Strategy in Classic Indian Rummy

- **arXiv ID**: [2601.00024](https://arxiv.org/abs/2601.00024)
- **Authors**: Purushottam Saha, Avirup Chakraborty, Sourish Sarkar, Subhamoy Maitra, Diganta Mukherjee, Tridib Mukherjee
- **Date**: 2025-12-26
- **Relevance**: ⭐⭐⭐ (3/5) — MEDIUM

## Summary

Rule-based framework for Indian Rummy using MinDist metric (edit distance from hand to nearest valid configuration). Dynamic pruning + pattern caching for efficient computation. Opponent hand-modeling in two-player zero-sum simulation. Significant win rate improvement over traditional heuristics.

## Relevance to GI TCG

- MinDist concept (structural proximity to completion) could inform deck evaluation metrics
- Rule-based approach provides interpretable baselines for comparison
- Less ML-heavy — complementary to pure RL approaches
- Opponent hand-modeling in card games is directly applicable
