# CGT × 七圣召唤：深度交叉分析

## 核心发现：现有系统已经在做 CGT，缺的是形式化框架

### 现状
17 个 scoring component 的**加法评分架构**本质上就是 CGT 的 disjunctive sum：
- `reaction_chain` = 元素反应子游戏的值
- `dice_fitness` = 骰子经济子游戏的值
- `tempo` = 先手优势子游戏的值
- `deck_prior` = 卡组策略子游戏的值

**缺失**: 温度加权。目前权重是静态的（训练或固定启发式），不是基于局面 urgency 动态分配。CGT 的核心洞察：**你在哪个子游戏行动，取决于哪个最"热"，而非哪个均值最大**。

## 一、骰子是冷却税——搜索深度应与骰子数反向

### CGT 视角
骰子 = cooling parameter t。
- 0 费卡：无冷却
- 3 费技能：冷却 3 单位

### 可证伪假说
> 骰子越多 → 搜索可以越浅；骰子越少 → 搜索必须越深

**原因**: 多骰子时选项多，边际差异小（低温）→ 浅搜够。少骰子时每个选择都关键（高温）→ 需要看清连锁后果。

**验证**: branch-eval 数据上按骰子数分组，比较 depth=3 vs depth=6 的决策一致性。预测：8 骰时一致性 >80%，2 骰时 <50%。

### 工程化
在 GiMlPolicy.choose() 加一行：
```
depth = max(2, min(8, round(14 - diceCount * 1.5)))
// 8骰→depth2; 3骰→depth8
```

## 二、角色组是天然子游戏分解——但需处理骰子耦合

### 关键障碍
骰子是共享资源 → 子游戏不是真正独立的。但 CGT 的"coupon game"概念提供解决方案：先估算每个子游戏的"温度×预期收益"，按比例分配搜索时间。

### 可证伪假说
> 按温度分配搜索深度 > 固定深度搜索

**验证**: 同一局面，uniform depth=4 vs temperature-weighted depth，比较 value model 预测准确率。

### 工程化
scoring component 输出从标量扩展为 `{value, temperature}`，choose() 按 max temperature 排序 candidate actions。

## 三、可逆性剪枝——最直接性能提升

| 你的行动 | 对手廉价回应 | 可逆？ |
|---------|------------|:---:|
| 切角色（1 费） | 对手也切（1 费） | ✅ 可逆 |
| 上元素 | 对手切到免疫角色 | ✅ 可逆 |
| 普通攻击 | 对手奶回来 | ⚠️ 部分可逆 |
| 开 Burst | 无可逆回应 | ❌ 不可逆 |
| 出天赋卡 | 对手无法 undo | ❌ 不可逆 |

### 可证伪假说
> 识别可逆行动并剪枝，可在损失 <5% 决策质量下减少 30-50% 搜索节点

**验证**: branch-eval 数据上统计可逆行动占比和 top-1 命中率。

### 工程化（~100 行）
```
isReversible(action, state):
  cost = action 的骰子成本
  opponentResponses = 对手 ≤cost 的行动
  for 每个回应:
    afterResponse = simulate(state, action, response)
    if evaluate(afterResponse) >= evaluate(state):
      return true  // 对手廉价反制 → 你的行动可逆
  return false
```

## 四、Thermograph 指导 MCTS budget 分配

### CGT 视角
高温区需要深搜（先手优势大），低温区均值估算就够（先手优势收敛）。

### 七圣映射
```
simulations(node) = BASE + temperature(node) * SCALE
```
- 高温节点（对手 Burst 满，反应窗口开）→ 更多 sims
- 低温节点（双方普通攻击）→ 更少 sims

### 可证伪假说
> temperature-weighted MCTS 在相同总 sim 数下 > uniform MCTS

## 五、Mean Value 作为快速 leaf evaluation

### 当前局限
value model (GBDT/MLP) 输出单一标量，隐含地混合了 mean 和 temperature。

### 改进方向
```
V(state) = mean_value(state) + temperature_adjustment(state, who_moves_first)
```

**收益**: 低温局面直接用 mean 评估——速度快且精度损失小。

## 六、实验优先级（修订版）

| 优先级 | 概念 | 改动量 | 预期影响 | 可证伪性 | 备注 |
|:---:|---|:---:|:---:|:---:|---|
| **P0** | 可逆性剪枝 | ~100 行 | 搜索节点 -30~50% | ⭐⭐⭐⭐⭐ | 最直接性能提升 |
| **P1** | 骰子→深度反向 | 1 行 | 避免算力浪费 | ⭐⭐⭐⭐ | 成本几乎为0 |
| **P2** | Number/Non-number 快速分类 | ~80 行 | 冷局面跳过搜索 -40%时间 | ⭐⭐⭐⭐⭐ | 基于**对手潜在伤害计算**，非固定阈值 |
| **P3** | 温度加权 move ordering | 改 scoring 输出 | AB 剪枝更高效 | ⭐⭐⭐⭐ | 与 P2 互补 |
| **P4↓** | 角色级子游戏近似分解 | 新增模块 ~200 行 | 减分支因子 ~2x | ⭐⭐⭐ | ⚠️ **降级**：流浪者跨角色攻击、千叶浮梦全队 buff 使分解不精确，仅作启发式 |
| **P5** | Mean/Temp 分离 value model | 改训练 pipeline | value 更准 | ⭐⭐ | 需重新训练，成本高 |

**修订说明（基于 2026-05-24 批注）：**
- P3→P4↓：角色级分解因跨角色攻击与全队装备加成而无法精确等价，从"独立子游戏"降为"启发式近似"。预期收益从 3-5x 下调至 ~2x。
- P2 新增：将 Number Avoidance 从概念转为可执行实验——基于计算对手**最大潜在伤害**而非固定 HP 阈值判断冷/热局面，与 Siegel §3.1 批注对齐。

## 关键定理速查

| 定理 | 陈述 | 七圣映射 |
|------|------|---------|
| Temperature of sum | t(G+H) ≤ max(t(G), t(H)) | 整体 urgency ≤ 最热子游戏 |
| Reversibility | G^LR ≤ G → 可 bypass | 对手廉价抵消的行为不深搜 |
| Mean Value | G_t → m(G) as t→∞ | 骰子耗光→收敛到基本面 |
| Cooling | 行动税收降 urgency | **骰子消耗=冷却税** |
| Number Avoidance | 不需要在 number 上行动 | 冷局面不搜 |
| Sentestrat | 高温=sente，低温=gote | Burst=sente，普攻=gote |
