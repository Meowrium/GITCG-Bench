## Summary

Proposes a hybrid RL framework for Axie Infinity (a complex blockchain card game with huge action space). Instead of evaluating every action in the full feasible set, the method learns action representations and evaluates actions in a fixed-size set determined by those representations. Demonstrates best winning rate and sample efficiency compared to two baseline methods.

## Key Contributions

- **Action representation learning**: Learns compact embeddings for the game's large action space
- **Fixed-size action evaluation**: Evaluates only a learned subset, dramatically reducing computational cost
- **Hybrid RL framework**: Combines representation learning with policy optimization
- **Real-world card game validation**: Tested on Axie Infinity, a commercially deployed complex card game

## Connection to Our Work

- **Action space is THE bottleneck for GI TCG**: GI TCG has an enormous action space (multiple characters, skills, dice costs, card plays, swaps). Action representation learning is a direct solution.
- **Embedding approach**: Could learn embeddings for GI TCG actions (play skill X on character Y with dice Z) to reduce MCTS branching factor
- **Sample efficiency**: The representation-based approach improved sample efficiency — critical for RL training on GI TCG
- **Generalization**: Action representations may enable cross-deck generalization (similar actions across different decks share embeddings)

## Critical Assessment

**Strengths**: Addresses a core problem (large action spaces in card games); practical focus on a real game.  
**Weaknesses**: Low citation count (2); Axie Infinity-specific implementation; limited architectural detail in paper; pre-LLM era methods.  
**Reproducibility**: Low — no code released; architecture described at a high level only.
