# Don't Overthink It: Inter-Rollout Action Agreement as a Free Adaptive-Compute Signal for LLM Agents (TrACE)

- **arXiv ID**: [2604.08369](https://arxiv.org/abs/2604.08369)
- **Authors**: Khushal Sethi
- **Date**: 2026-04-09
- **Venue**: arXiv preprint
- **Relevance Score**: ⭐⭐⭐⭐⭐ (5/5 — SC→消极决策的直接继承者，自适应 compute)

## Summary

提出 TrACE（Trajectorical Adaptive Compute via agrEement），训练无关的自适应计算控制器：在每个 timestep 采样少量候选动作，测量 inter-rollout action agreement。**一致性高** → 容易决策，立即提交；**一致性低** → 不确定，增加采样直到达到上限再 commit。本质上是 self-consistency 的“按需使用”版本——只在对不确定时才多采。

## Key Contributions

- 首个 training-free、per-timestep adaptive-compute 控制器（用于多步序列决策 agent）
- 用 inter-rollout action agreement 作为「步骤成功率」的可靠信号，无需额外训练/verifier/人工标注
- TrACE-4 在 GSM8K 上匹配 SC-4 精度但减少 **33%** 调用；在 MiniHouse 上减少 **39%**
- TrACE-8 匹配 SC-8 精度但减少 **55%** 调用（GSM8K）和 **65%**（MiniHouse）

## Connection to Our Work

- **直接对接 PokeLLMon 的 panic switching 机制**：TrACE 的 "low agreement = uncertainty" 信号可以精确检测 GI TCG agent 何时进入 panic 状态
- **自适应 compute 节省 token**：不需要每个 step 都采 N 次——只在 LLM 不确定时才多采，平均成本接近 greedy
- **无训练、无外部 verifier**：纯 prompt + sampling 层，可以直接嵌入 DecisionFragment pipeline

## Critical Assessment

**Strengths**: 极简设计（training-free）、自适应节省计算、已验证多步序列决策场景、Qwen 3B 小模型即可运行。

**Weaknesses**: 单作者、2026 年新论文、MiniHouse 仅 30 步 benchmark（规模有限）、未在 competitive game 上验证。
