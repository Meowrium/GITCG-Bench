# Tree of Thoughts as a Classical Heuristic Search Problem: Formal Foundations and Design Patterns
- arXiv ID: 2605.28566
- Authors: Guni Sharon
- Date: 2026-05-27
- Relevance Score: ⭐⭐⭐⭐

## Summary
Synthesizes the fragmented Tree-of-Thoughts (ToT) literature into a unified taxonomy based on classical heuristic search terminology. Maps LLM-based reasoning to classical search components: state representation (thought granularity), successor generation (prompting operators), and heuristic evaluation (self-assessment). Identifies design patterns: Best-First Search for shallow deterministic tasks, DFS/MCTS for deep multi-step reasoning. Calls for the heuristic search community to engage with LLM reasoning, identifying open algorithmic challenges at their intersection.

## Key Contributions
- **Unified ToT taxonomy**: First systematic mapping of LLM tree search to classical heuristic search concepts
- **Design pattern identification**: BFS for shallow tasks, MCTS for deep reasoning — actionable guidance for system design
- **Cross-community bridge**: Connects NLP/LLM and automated planning/heuristic search communities
- **Open challenges**: Identifies gaps at the heuristic search × LLM reasoning intersection

## Connection to Our Work
- **LLM deck prior architecture**: Our LLM component that estimates deck quality from game state is essentially a heuristic evaluation function — this taxonomy provides formal foundations for how to structure it
- **MCTS + LLM integration**: The DFS/MCTS pattern for deep reasoning maps directly to GI TCG's multi-turn planning needs
- **Thought granularity**: Helps decide whether LLM evaluation should operate at card-level, turn-level, or game-level granularity
- **Successor generation**: Formal framework for how LLM should propose candidate actions (decks/card plays) for MCTS expansion

## Critical Assessment
**Strengths**: Much-needed unification of a fragmented field, clear and actionable taxonomy, bridges two communities effectively. Good synthesis paper.

**Weaknesses**: Pure taxonomy/position paper — no new algorithms or experiments. Single author. Doesn't address imperfect information search specifically.
