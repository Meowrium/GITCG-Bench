# 组合博弈论 × 七圣召唤：概念速通

## 研究背景

**日期:** 2026-05-23
**目标:** 将 CGT 应用于 GI TCG AI 策略改进——剪枝、值估计、搜索深度分配。
**核心参考:** Siegel《组合博弈论》(2013)、Conway《论数与游戏》(1976)、Berlekamp/Conway/Guy《胜之道》(1982)

---

## 一、不交和与游戏分解

### 定义
两个游戏 G 和 H 的**不交和** G+H：每回合玩家只在**一个**组件中行动，其他组件不变。

数学形式：G + H = { G^L + H, G + H^L | G^R + H, G + H^R }

### 七圣映射

**能自然分解的：**
1. 场上角色 + 后备角色 + 召喚物/支援牌 ≠ 独立子游戏组——**流浪者可攻击后台角色**，分解不干净。
2. 装备（武器/圣遗物）不限于修改其所属角色——**千叶浮梦等为全队加成**（我方元素反应伤害+1），打破独立性。
3. 召喚物是短命、确定性行为的子组件——贡献可按时间衰减预计算，但同样受全队 buff 影响。

**关键障碍：骰子经济耦合 + 跨角色交互。** 骰子是共享资源池，且攻击目标、全队 buff 等交互使 classic disjunctive sum 的独立性假设在此不成立。处理方案：用 CGT 的"coupon game"概念做**启发式近似**——先估算每个子组件的"温度×预期收益"，按比例分配搜索预算。**分解只是启发式，不是精确等价。**

### 工程化收益
- 分支因子从 O(100+) 降到 O(按温度过滤的候选数 × 耦合修正)
- 预估搜索节点减少 2-3 倍（比原本估计保守，因分解不精确）

## 二、温度与 Thermograph

### 定义
**温度**衡量一个局面的"紧迫度"——先手方在该组件行动有多大优势。高温=urgent，低温=可以放着不管。

**Thermograph**是温度的可视化：显示游戏值如何随着 cooling 参数变化。

### 关键定理
t(G+H) ≤ max(t(G), t(H)) ——和的温度不超过最热组件的温度。

### 七圣映射

| 高温（urgent） | 低温（不紧迫） |
|---|---|
| 对手 Burst 能量满 | 双方都普通攻击 |
| 角色即将死亡 | 装备提供被动价值 |
| 元素反应窗口打开 | 后宫无切人选项 |
| 回合末未用骰子 | 场面均势无反应链 |

### 工程化
- 按组件温度分配搜索深度：高温深搜（depth=6-8），低温浅搜（depth=1-2）
- 温度引导 alpha-beta 排序：先探索高温分支
- 如果温度≈0（冷局面），直接用 heuristic，不搜索

## 三、冷却（Cooling）

### 定义
**冷却**是对行动施加"税收"来降低 urgency 的操作。冷却后的游戏 G_t：行动者必须支付 t 给对手。

数学形式：G_t = { G^L_t - t | G^R_t + t }

### 七圣映射：骰子 = 冷却税

- 0 费卡：无冷却，纯游戏值
- 3 费技能：冷却 3 单位，收益必须超过冷却
- 切人 1 费：冷却税 1

### 反直觉推论
> **骰子越多 → 搜索越浅；骰子越少 → 搜索必须越深**

多骰子时选项多，边际差异小（低温）→ 浅搜就够。少骰子时每个选择都关键（高温）→ 不深搜看不出连锁后果。

## 四、均值定理

### 定义
冷却 → ∞ 时，游戏值收敛到一个数，称为**均值** m(G)。均值代表"双方最优轮流玩、没有先手优势偏差"的预期结果。

### 七圣映射
- **Mean** = "基本面"（HP 领先 + 资源领先 + 场面优势）
- **Temperature** = "战术机会"（先手方额外优势）

V(state) = mean(state) + temperature_adjustment(state, who_moves_first)

### 工程化
- 低温局面直接用 mean 做 leaf evaluation（替代昂贵的 rollout）
- 不需要精确值，只需要值落在哪个区间（大优/小优/均势/小劣/大劣）

## 五、可逆性与剪枝

### 定义
一个行动是**可逆的**，如果对手能用廉价回应使行动收益归零。CGT 的简化规则：可逆行动可以被 bypass，不需要深搜。

数学定义：如果存在 Right option G^LR 使得 G^LR ≤ G，则 G^L 可逆。

### 七圣可逆行动

| 你的行动 | 对手廉价回应 | 可逆？ |
|---------|------------|:---:|
| 切角色（1 费） | 对手也切角色（1 费） | ✅ |
| 上元素 | 对手切到免疫/清除的角色 | ✅ |
| 普通攻击 | 对手奶回来/切人 | ⚠️ |
| 开 Burst | 无可逆回应 | ❌ |
| 出关键天赋卡 | 对手无法 undo | ❌ |

### 工程化
- 新增 reversibility scorer（~100 行代码）
- 预估剪枝 30-50% 搜索节点
- 验证：branch-eval 数据上 top-1 选择中可逆行动占比应 <5%

## 六、Sentestrat（先手/后手分类）

- **Sente**（先手有利行动）：对手必须回应，不回应就亏
- **Gote**（后手有利行动）：对手可以忽略

在七圣中：
- Burst = sente（对手必须做点什么）
- 普通攻击 = gote（对手可以继续自己的计划）
- 关键反应窗口 = sente
- 被动装备 = gote

## 七、实验优先级（修订版）

| 优先级 | 概念 | 改动量 | 预期影响 | 备注 |
|:---:|---|:---:|:---:|---|
| **P0** | 可逆性剪枝 | ~100 行 | 搜索节点 -30~50% | |
| **P1** | 骰子→搜索深度反向 | 1 行 | 避免算力浪费 | |
| **P2** | Number/Non-number 快速分类 | ~80 行 | 冷局面跳过搜索 | 基于**对手潜在伤害计算** |
| **P3** | 温度加权 move ordering | 改 scoring 输出结构 | Alpha-beta 更高效 | |
| **P4↓** | 角色级子游戏近似分解 | 新增模块 ~200 行 | 减分支因子 ~2x | ⚠️ **降级**：分解不精确 |
| **P5** | Mean/Temperature 分离 value model | 改训练 pipeline | value 预测更准 | 成本高，需重新训练 |

**修订说明（2026-05-24）：**
- 原 P3（角色级子游戏分解）降为 P4：跨角色攻击（流浪者打后台）+ 全队装备加成（千叶浮梦）使 disjunctive sum 假设不成立。分解从"精确等价"降为"启发式近似"，预期收益从 3-5x 下调至 ~2x。
- 新增 P2（Number/Non-number 分类器）：将 Siegel §3.1 的 Number Avoidance 从理论转化为可执行实验——基于计算对手最大潜在伤害（非固定 HP 阈值）判断冷/热局面。
