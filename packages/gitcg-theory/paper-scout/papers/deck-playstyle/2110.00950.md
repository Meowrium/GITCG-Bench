# An Unsupervised Video Game Playstyle Metric via State Discretization

- **arXiv ID**: [2110.00950](https://arxiv.org/abs/2110.00950)
- **Authors**: Chiu-Chou Lin, Wei-Chen Chiu, I-Chen Wu (3 authors — 台湾交大，I-Chen Wu 是知名游戏 AI 研究者)
- **Date**: 2021-10-03
- **Venue**: arXiv preprint (cs.AI, cs.CV, cs.LG)
- **Citations**: Unknown
- **Relevance Score**: ⭐⭐⭐⭐⭐ (5/5 — 直接对焦 behavior spectrum 方案)

## Summary

提出第一个从游戏观察和动作中直接提取玩家风格（playstyle）的无监督度量方法，不需要任何人工指定的 playstyle 特征定义。通过状态离散化（state discretization）将游戏轨迹编码为行为向量，再用无监督方法聚类。此前的研究依赖启发式规则或需要游戏环境支持的 hand-crafted behavior features，开发成本高且泛化差。

## Key Contributions

- 首个不依赖人工定义的 playstyle 度量——直接用 state-action trajectory
- 状态离散化方法：将连续游戏状态映射到离散 representation
- 无监督聚类区分不同 playstyle
- 无需游戏环境支持或开发者定义的特征

## Connection to Our Work

- **直接对焦 behavior spectrum 方案**：他们的问题和我们一模一样——"不用手工定义的 aggro/midrange/control 标签，从 game data 无监督提取 playstyle"
- **状态离散化 vs 我们的行为度量**：他们用 state discretization，我们计划用 behavior metrics（damage_per_round, swap_count 等）。两种方式可以互补——behavior metrics 作为可解释维度，state discretization 捕获隐式模式
- **I-Chen Wu 的连接**：作者来自台湾交大，Wu 是莫拉（MoHex）、AlphaGo 相关研究的关键人物——游戏 AI 领域的权威
- **可直接复用到 GI TCG**：playstyle = deck behavior，game observations = replay states，actions = replay action sequences

## Critical Assessment

**Strengths**: 方法通用、不需要领域知识、可直接复现；来自知名游戏 AI 研究组。
**Weaknesses**: 2021 年论文，可能只有概念验证级别游戏（而非复杂 CCG）；状态离散化在 GI TCG 高维状态空间中可能面临维度灾难。
**Reproducibility**: Moderate — 方法论清晰。
