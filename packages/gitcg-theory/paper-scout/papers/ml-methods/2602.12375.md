## Summary

乐观价值估计（optimistic value estimates）是 RL 中 directed exploration 的一种机制——agent 对 value + bonus 贪婪行动。传统方法通过 reward bonus 传播不确定性来学习 value bonus，但这只是"事后"增加 bonus（只有在看到高奖励后才增加）。本文提出一种方法，让 agent 在首次访问 unknown state-action 时就能获得 exploration bonus。

## Key Contributions

- Exploration bonus 的前瞻性计算（而非仅 retroactive）
- Ensemble errors 作为 uncertainty measure
- 直接适用于任何 ensemble-based value estimation 方法

## Connection to Our Work

- **GBDT 天然是 ensemble**：GBDT 是多棵树的集合，天然提供 uncertainty estimate（不同树的输出方差）。这篇论文的方法可以直接应用到 GBRL 或其他 GBDT-based value model 上
- **MCTS 的 exploration 增强**：当前 MCTS 用 PUCT（UCB-based exploration）。ensemble error 可以作为一个额外的 exploration bonus 项——"GBDT 内部对这个状态的评估分歧大 → uncertainty 高 → 应该多探索"
- **与 CGT cold-hot 对接**：cold 节点的含义之一就是"value 不确定"——ensemble variance 可以作为 cold-hot score 的一个来源

## Critical Assessment

**Strengths**: 方法直接；ensemble-based approach 天然适合 GBDT；2026 年最新。
**Weaknesses**: 新论文实验有限；可能只在特定环境下验证。
**Reproducibility**: Moderate — 方法论清晰但需要适配到 GBDT。
