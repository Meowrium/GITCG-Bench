# Representational Collapse in Multi-Agent LLM Committees: Measurement and Diversity-Aware Consensus (DALC)

- **arXiv ID**: [2604.03809](https://arxiv.org/abs/2604.03809)
- **Authors**: Dipkumar Patel
- **Date**: 2026-04-04
- **Venue**: arXiv preprint
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — 关键警告：naive majority voting 可能无效)

## Summary

多个相同 LLM 用不同 role prompt 做 majority vote 时会发生 **表征坍缩**（representational collapse）：3 个 Qwen2.5-14B agent 在 GSM8K 上的 mean cosine similarity 为 0.888，effective rank 仅 2.17/3.0（即第 3 个 agent 几乎不贡献新信息）。提出 DALC：training-free 共识协议，基于 embedding geometry 计算 diversity weights。DALC 在 GSM8K 上达到 87% vs self-consistency 84%，同时减少 **26% token 成本**。

## Key Contributions

- 首次量化 multi-agent LLM 的**表征坍缩**现象
- 发现选择不同 embedding proxy 强烈影响坍缩程度（mxbai cos 0.908 vs nomic 0.888）
- DALC 协议：训练无关的 diversity-aware 共识，超过纯 self-consistency 且省 token
- 坍缩在高难度任务上更严重

## Connection to Our Work

- **对 SC 方案的直接警告**：如果我们用同一 LLM 多次采样做 action majority vote，采样结果可能高度相关（表征坍缩），投票不起作用
- **DALC 的 diversity weighting** 如果确实有效，可以作为 SC 的增强版
- **Embedding proxy 选择至关重要**：不同 embedding 模型对坍缩程度的影响差异显著（cos 0.888 vs 0.908）
- **PokeLLMon 的 SC(k=3) 有效**可能因为宝可梦的 action 空间离散且有限，坍缩不那么严重。GI TCG 需要验证

## Critical Assessment

**Strengths**: 揭示并量化了重要失败模式、DALC 简单有效、token 高效。

**Weaknesses**: 单作者、2026 年新论文、只在 GSM8K 上验证（非游戏/agent 场景）、embedding 选择敏感的发现需要跨模型验证。
