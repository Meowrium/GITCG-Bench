# Language Agents with Reinforcement Learning for Strategic Play in the Werewolf Game

- **arXiv ID**: [2310.18940](https://arxiv.org/abs/2310.18940)
- **Authors**: Zelai Xu, Chao Yu, Fei Fang, Yu Wang, Yi Wu (Tsinghua, CMU)
- **Date**: 2023-10-29
- **Venue**: ICML 2024
- **Citations**: Growing
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — LLM 出候选 + RL 选动作的架构模板)

## Summary

纯 LLM agent 在复杂决策中存在从训练数据继承的 intrinsic bias，导致次优性能。提出 LLM + RL 混合框架：LLM 做 deductive reasoning 产生候选语言动作，RL policy 从候选中选择最优动作。在狼人杀（社交推理游戏）上验证——需要灵活沟通 + 策略博弈。RL 训练的 agent 显著超越纯 LLM agent。

## Key Contributions

- **LLM + RL 混合决策架构**：LLM 负责产生候选 + RL 负责选择——分工明确
- **Intrinsic Bias 诊断**：纯 LLM 会系统性地偏好某些 action（如过度信任），RL 纠正了这种偏置
- **语言动作的 action space**：狼人杀的动作是自然语言（"我投票给 X 因为他..."），证明 RL 可以优化语言级动作选择
- **与 fine-tuning 正交**：RL policy 是轻量级的选择器，不需要微调 LLM

## Connection to Our Work

- **直接对标 Resolver**：你的 Resolver 是线性打分（固定权重）。Werewolf RL 的模式是「RL 学习权重」——从对局结果中优化各因子的重要性。这就是 **Resolver 的最大升级方向**。
- **GBRL 的天然对接**：GBRL (2407.08250) 做 GBDT + RL，这篇做 LLM + RL。二者结合 = LLM 出 DecisionFragment → GBDT 做 action/value 选择 → RL 优化 GBDT 参数。完整闭环。
- **候选动作质量 vs 选择质量**：论文证明——即使 LLM 的候选不是最优，RL 选择器仍能选出最好的那个。这对当前 Resolver 的权重调优有直接启发：不需要 LLM 完美，需要 Resolver 聪明。
- **Intrinsic Bias**：你的 GLM-5 和 MiniMax-M2.5 可能各自有系统性偏好（GLM-5 偏好激进？MiniMax 偏好保守？）。如果发现 P0/P1 胜率偏差 > 10%，这是 Intrinsic Bias 而非策略优势。

## Critical Assessment

**Strengths**: 清晰的 LLM+RL 分工；ICML 2024；验证了 RL 选择器 > 纯 LLM；与当前 Resolver 互补。
**Weaknesses**: 狼人杀的动作空间是离散语言（不涉及数值化的骰子/伤害计算）；RL 训练需要对局数据（for GI TCG：需要多少局？）。
**Reproducibility**: 需要 RL 基础设施，但架构清晰。
