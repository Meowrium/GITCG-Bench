# Voyager: An Open-Ended Embodied Agent with Large Language Models

- **arXiv ID**: [2305.16291](https://arxiv.org/abs/2305.16291)
- **Authors**: Guanzhi Wang, Yuqi Xie, Yunfan Jiang, Ajay Mandlekar, Chaowei Xiao, Yuke Zhu, Linxi Fan, Anima Anandkumar (NVIDIA, Caltech, Stanford, UT Austin)
- **Date**: 2023-05-25
- **Venue**: NeurIPS 2023 (Oral)
- **Citations**: Very High (landmark paper)
- **Relevance Score**: ⭐⭐⭐⭐⭐ (5/5 — Skill Library + Curriculum 直接映射)

## Summary

首个 LLM 驱动的具身终身学习 agent，在 Minecraft 中持续探索世界、获取多样技能、在无人类干预下做出新发现。三个核心组件：(1) **Automatic Curriculum** 最大化探索；(2) **Skill Library** 持续增长的、存储和检索复杂行为的可执行代码库；(3) **Iterative Prompting** 机制结合环境反馈、执行错误和自验证来持续改进程序。纯黑盒 GPT-4 查询，无需微调。技能是时序扩展的、可解释的、可组合的，agent 的能力快速复利增长。获得 3.3x 更多独特物品、旅行 2.3x 更远、解锁科技树里程碑快 15.3x。

## Key Contributions

- **Automatic Curriculum**：根据当前能力和探索进度，自主选择下一个子目标
- **Skill Library**：每个技能是可执行 JavaScript 函数，agent 遇到新挑战时先检索库中是否有类似技能、可以复用或组合
- **Iterative Prompting**：环境反馈 + 执行错误 + 自验证 → 持续改进 skill 代码，类似于 human-in-the-loop 但自动化
- **In-context Lifelong Learning**：不微调模型，技能库的增长使 agent 在没有遗忘的情况下持续变强

## Connection to Our Work

- **Skill Library → DecisionFragment 的 candidate_policies**：当前 candidate_policies 是人工定义的。Voyager 的模式是「从成功对局中自动提取策略」→ 存为可复用的 policy template → 类似局面下检索复用。这正是 PLAP 的 skill library + 你的 DecisionFragment 的组合。
- **Automatic Curriculum → PlanV2 动态生成**：当前 PlanV2 是开局一次生成。Voyager 的 curriculum 根据「还剩多少对手角色」「当前资源水平」动态选择子目标——对应 PlanV2 的 mid-game replan。
- **Iterative Prompting → Critic + Fragment 循环**：Voyager 的 feedback → code improvement 就是你的 `get_execution_feedback_v1 → critic_evaluate_v1 → 下一个 DecisionFragment` 循环。但 Voyager 的关键是 feedback 直接用来**改写 skill 代码**，而不仅仅是 replan。
- **可组合性是最大启示**：Voyager 的 skill 可以组合（skill A 的输出是 skill B 的输入）——DecisionFragment 之间应该也可以组合为 combo 链。

## Critical Assessment

**Strengths**: 终身学习、技能复利增长、纯 inference-time 方案、可组合技能设计优雅。
**Weaknesses**: Minecraft 是开放世界（与回合制 TCG 不同）；skill 是可执行代码（TCG 的 skill 可能更适合 JSON 模板）；不涉及不完备信息博弈。
**Reproducibility**: 架构清晰，但 Minecraft 模拟器依赖大。
