# PRISM-MCTS: Learning from Reasoning Trajectories with Metacognitive Reflection
- arXiv ID: 2604.05424
- Authors: Siyuan Cheng, Bozhong Tian, Yanchao Hao, Zheng Wei
- Date: 2026-04-07
- Relevance Score: ⭐⭐⭐⭐

## Summary
PRISM-MCTS addresses a key inefficiency in MCTS: each rollout is treated as an isolated trajectory with no information sharing. Drawing inspiration from human parallel thinking, PRISM-MCTS integrates a Process Reward Model (PRM) with dynamic shared memory that captures "Heuristics" (successful strategies) and "Fallacies" (error-prone branches). This shared memory reinforces good paths and prunes bad ones across rollouts, halving trajectory requirements on GPQA while surpassing MCTS-RAG and Search-o1. Includes a data-efficient PRM training strategy for few-shot regimes. Published at ACL 2026 Findings.

## Key Contributions
- **Shared memory MCTS**: Rollouts share information via PRM-guided heuristics/fallacies memory, unlike standard isolated-rollout MCTS
- **PRM training strategy**: Data-efficient process reward model training under few-shot constraints
- **Metacognitive reflection**: Framework for learning from both successes and failures across rollouts
- **Strong empirical results**: 50% trajectory reduction on GPQA, outperforms MCTS-RAG and Search-o1

## Connection to Our Work
- **MCTS efficiency**: GI TCG has a massive state space; PRISM-style shared memory could reduce redundant exploration
- **PRM for game evaluation**: Adapt PRISM's process reward model to evaluate intermediate game states (turn-by-turn advantage) instead of only terminal rewards
- **Heuristics/Fallacies memory**: Track which card plays/strategies are historically strong vs. weak across self-play training
- **Data-efficient training**: GI TCG data is scarce; PRISM's few-shot PRM training is relevant

## Critical Assessment
**Strengths**: Novel MCTS architecture, ACL venue adds credibility, strong experimental results, shared memory is a genuinely useful idea.

**Weaknesses**: Applied to LLM reasoning (not games), PRM trained on text — unclear how to adapt to game state representations. No comparison to game-specific MCTS variants (e.g., AlphaZero).

**Reproducibility**: Low-moderate — ACL paper, likely to have code but no link in abstract. PRM training requires labeled process data.
