## HIGH Relevance — Deep Analysis

### 1. Causal RL for MTG (2605.06066) ⭐⭐⭐⭐⭐

📄 [Full analysis](papers/2605.06066.md) | [arXiv](https://arxiv.org/abs/2605.06066) | 0 citations

**TL;DR**: Gymnasium benchmark combining MTG with an explicit Structural Causal Model. First testbed that simultaneously evaluates causal credit assignment, masked action spaces, and cross-archetype transfer. CGFA-PPO agent uses SCM parents as factor-aligned critic targets.

**Why it matters**: MTG's complexity (deck construction, hidden info, sequential play) parallels GI TCG. The SCM approach bridges to Combinatorial Game Theory. The statistical evaluation protocol (paired bootstrap, Holm-Bonferroni) is a gold standard we should adopt.

**Action**: Evaluate MTG-Causal-RL as a testbed for GBDT ranker interpretability. Adopt the evaluation protocol.

### 2. Code World Models for General Game Playing (2510.04542) ⭐⭐⭐⭐⭐

📄 [Full analysis](papers/2510.04542.md) | [arXiv](https://arxiv.org/abs/2510.04542) | 9 citations

**TL;DR**: LLM translates game rules → executable Python world model (state transitions, legal moves, termination, value heuristics, inference). MCTS plans on the generated model. Outperforms Gemini 2.5 Pro on 9/10 games including imperfect information card games.

**Why it matters**: Closest work to our vision — an LLM that understands GI TCG rules and generates an executable game model. The 3-layer architecture (transition + heuristic + inference) is a template for our LLM deck prior. Authors overlap with CSRO (DeepMind game AI team).

**Action**: Prototype whether an LLM can generate a correct GI TCG world model. Study inference function for opponent hand estimation.
