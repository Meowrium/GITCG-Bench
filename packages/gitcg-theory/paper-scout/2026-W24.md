### 1. Solving Pasur GPU CFR (2508.06559) ⭐⭐⭐⭐⭐

📄 [Full analysis](papers/2508.06559.md) | [arXiv](https://arxiv.org/abs/2508.06559)

**TL;DR**: First complete CFR solution for a fishing card game (Pasur) with >10^9 node game tree. CUDA-accelerated framework with novel game tree decomposition (card states × accumulated scores). Round-by-round backward training from endgame to early game. Equilibrium strategies distilled into tree-based model for real-time gameplay. GPU self-play evaluates 10,000 games/matchup for deck fairness.

**Why it matters**: The round-by-round decomposition methodology is directly applicable to GI TCG's multi-round structure. The CFR → tree distillation pipeline offers an alternative to end-to-end MCTS+RL. GPU memory management patterns are reusable.

**Action**: Study backward training strategy for GI TCG endgame solving. Evaluate decomposed game tree representation for GI TCG.
