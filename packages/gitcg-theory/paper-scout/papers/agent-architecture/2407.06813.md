# Richelieu: Self-Evolving LLM-Based Agents for AI Diplomacy

- **arXiv ID**: [2407.06813](https://arxiv.org/abs/2407.06813)
- **Authors**: (2024 paper, multi-institution)
- **Date**: 2024-07-09
- **Venue**: NeurIPS 2024
- **Citations**: Growing
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — Self-Evolution 的完整 Agent 生命周期)

## Summary

提出 Richelieu——用于外交游戏 (Diplomacy) 的自我进化 LLM agent。三个核心阶段：(1) **Strategic Planning**：记忆 + 反思 → 目标导向计划；(2) **Goal-Oriented Negotiation**：基于计划与其他玩家谈判；(3) **Self-Evolution**：通过 self-play 自动发现 weaknesses → 反思 → 更新策略库。不需要人类标注或 fine-tuning。

## Key Contributions

- **Self-Evolution 循环**：Planning → Execution → Reflection → Strategy Update → 下一局更强的 Planning
- **Memory/Reflection 集成**：与 Generative Agents 类似，但面向博弈游戏
- **Goal-Oriented Negotiation**：计划不是固定的——根据谈判结果动态调整
- **Weakness Discovery**：Self-play 自动暴露策略短板

## Connection to Our Work

- **PlanV2 的动态更新**：当前 PlanV2 是开局生成、全场不变。Richelieu 的模式是「每局结束后反思 → 更新策略 → 下局更强」。这比 Critic 的 mid-game replan 更彻底——是跨局的 PlanV2 进化。
- **Self-Evolution → 策略库**：当前 strategy_store 存的是固定锚点。Richelieu 的策略库是动态进化的——失败的策略被降权、成功的策略被增强。你的 strategy_store 可以增加一个 `confidence` 字段。
- **弱点了发现**：Self-play 最宝贵的副产品——「这个策略为什么输了」。对你的价值不只是 win rate，而是**自动发现 PlanV2 中的不合理假设**（如「T3 能爆发」但实际很少达到）。

## Critical Assessment

**Strengths**: 完整的 Agent 生命周期设计；NeurIPS 2024；自我进化不需要人类标注。
**Weaknesses**: Diplomacy 是 7 人外交游戏（多 agent 协调），与 2 人 TCG 不完全一致；Negotiation 阶段与 TCG 无关。
**Reproducibility**: 架构清晰但工程量大。
