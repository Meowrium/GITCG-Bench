# Reflexion: Language Agents with Verbal Reinforcement Learning

- **arXiv ID**: [2303.11366](https://arxiv.org/abs/2303.11366)
- **Authors**: Noah Shinn, Federico Cassano, Ashwin Gopinath, Karthik Narasimhan, Shunyu Yao (Princeton, Northeastern)
- **Date**: 2023-03-20
- **Venue**: NeurIPS 2023
- **Citations**: High (major paper)
- **Relevance Score**: ⭐⭐⭐⭐⭐ (5/5 — Critic 跨局学习的核心机制)

## Summary

LLM agent 通过试错学习面临挑战——传统 RL 需要大量训练样本和昂贵微调。Reflexion 提出**不更新模型权重，而是通过语言反馈来强化 agent**：agent 口头反思任务反馈信号，将反思文本维护在 episodic memory buffer 中，在后续尝试中诱导更好的决策。灵活支持多种反馈类型（标量值或自由文本）和来源（外部或内部模拟）。HumanEval coding 达到 91% pass@1（GPT-4 baseline 80%）。

## Key Contributions

- **Verbal RL**：用语言反思代替参数更新——Agent 自省「我哪里做错了」并记住
- **Episodic Memory Buffer**：跨任务的持久记忆，每次运行时回看历史反思
- **三类反馈**：外部反馈（环境结果）、内部反馈（自评）、标量反馈（分数）都可作为反思材料
- **与权重更新正交**：可以和传统 RL 叠加使用

## Connection to Our Work

- **Critic 的跨局扩展**：当前 Critic 评估单局内的决策质量（`should_replan`），不产生跨局 insight。Reflexion 的模式是：每局结束后 → Critic 写 3 条 verbal reflection → 存入 `strategy_store` → 下局开局注入 prompt。
- **Episodic Memory 的工程实现**：`strategy_store(action="save", key="p0_lessons")` 天然支持——只需要 Critic 增加 `cross_game_lessons` 输出字段。
- **三种反馈类型都适用 GI TCG**：外部反馈（赢/输/HP差）、内部反馈（决策一致性评分）、标量反馈（Critic.score）。
- **反思质量**：Reflexion 发现「反思太笼统」无效——需要具体到「T2 第 3 步切班尼特过早」。这对 Critic 的 `suggested_adjustments` 格式有启示。

## Critical Assessment

**Strengths**: 不微调模型、设计简洁、跨任务记忆有效、与现有管道无冲突。
**Weaknesses**: 依赖 LLM 自身的反思质量（garbage in, garbage out）；无选择性遗忘机制（MemoryAgentBench 暴露的问题）；episodic memory 增长无上限。
**Reproducibility**: 高——只需 prompt 改造。
