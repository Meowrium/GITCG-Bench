# Beyond Outcome-Based Imperfect-Recall: Higher-Resolution Abstractions for Imperfect-Information Game Solving

- Authors: (from arXiv)
- Date: 2025-10-16

## Summary
This paper introduces higher-resolution abstractions for imperfect-information game solving that go beyond traditional outcome-based imperfect-recall approaches. The method creates finer-grained information state groupings, allowing CFR-based solvers to make more precise strategic distinctions while maintaining computational tractability. The approach bridges the gap between full-recall (expensive but accurate) and imperfect-recall (cheap but lossy) abstractions.

## Key Contributions
- Novel abstraction framework with higher resolution than standard imperfect-recall
- Theoretical analysis of resolution vs. computational cost tradeoff
- Empirical validation showing improved solution quality over standard imperfect-recall abstractions
- Domain-independent approach applicable to any extensive-form game

## Connection to Our Work
- **State abstraction for GI TCG**: The massive state space of GI TCG (deck × hand × board × history) demands abstraction. This work provides a principled framework for deciding which states to group together, potentially applicable to GI TCG's information sets.
- **Resolution-computation tradeoff**: Directly relevant to GI TCG where we must balance state space fidelity against MCTS simulation budget.

## Critical Assessment
**Strengths**: Principled theoretical foundation. Clear improvement over standard imperfect-recall. Domain-independent.

**Weaknesses**: Evaluated primarily on poker variants — unclear how well it generalizes to games with more complex action spaces like GI TCG.
