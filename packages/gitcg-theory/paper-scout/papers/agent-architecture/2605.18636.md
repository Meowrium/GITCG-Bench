## 核心思路

**Event-triggered deliberation**: 战略推理应跨稳定段摊销，仅在事件边界重新调用。把长程游戏控制视为推理资源分配问题。

## 架构：SPIKE 双控制器

```
Event Trigger → 决定何时 escalate
    ├── Strategic Controller (低频): 全局规划、失败分析、恢复
    └── Reactive Controller (高频): 快速本地执行，严格 token 预算

Hierarchical Memory:
    ├── SA-MB (State-Action Memory Bank): 短时本地动作先验
    └── SA-KG (State-Action Knowledge Graph): 结构化战略证据
```

## Event Trigger 信号 (公式 3)

- **c_t ≥ T**: Reactive 步数超 refresh 间隔
- **d_t > τ_v**: 视觉不连续 (cosine distance)
- **z_t ≥ τ_z**: 进度停滞
- **r_t ≥ τ_r ∧ z_t ≥ τ_rz**: 行为重复 + 停滞
- **ℓ_t ≥ τ_ℓ**: 执行失败 (F1/F2/F3 分级)

SPIKE 56.4% vs CRADLE 43.6% (+12.8pp), -48.5% tokens, -47.1% latency

## Ablation 发现

- 去掉 Event Trigger → SR: 18.0→15.7%
- 去掉 Reactive Override → SR: 18.0→15.7%
- 去掉 SA-MB → SR: 18.0→15.0%
- 去掉 SA-KG → SR: 18.0→14.3%
- 仅 Single Strategic → 最高 16.3%，但 tokens 305.4k
- 仅 Single Reactive → 最高 10.3%

## Agent Architecture 详情

**Strategic Controller 工作流**: Info Collection → Self Reflection → Task Reasoning → Action Proposal (short-horizon, T steps)

**Reactive Controller**: 严格 token 预算下执行，允许 bounded local corrections（但不能更改 subgoal）

**SA-MB 检索评分**: 基于 Jaccard overlap + token cosine + reward EMA + success rate，加上 recency decay

**SA-KG 检索评分**: 基于 vector similarity + action success rate

## 对 GI TCG 的参考价值

| 模块 | TCG 类比 |
|------|---------|
| Event Trigger | 关键回合检测（对手出关键牌、血量阈值、资源转折点） |
| Strategic Controller | 深度规划（MCTS rollout、长期策略） |
| Reactive Controller | 常规回合快速决策 |
| SA-MB | 短时对局记忆（最近几回合的状态-动作对） |
| SA-KG | 跨对局战略知识图谱（某 archetype 对某 archetype 的应对模式） |
