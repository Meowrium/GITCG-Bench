## Summary

现有 LLM agent benchmark 主要评估推理、规划和执行能力，memory 能力（agent 如何记忆、更新、检索长期信息）缺乏评估。基于记忆科学和认知科学经典理论，提出 memory agent 四个核心能力维度：(1) 准确检索，(2) 测试时学习，(3) 长程理解，(4) 选择性遗忘。将现有长上下文数据集转化为多轮增量格式，模拟 agent 逐步积累信息的过程。

## Key Contributions

- **四维记忆能力框架**：准确检索 / 测试时学习 / 长程理解 / 选择性遗忘
- **MemoryAgentBench**：首个全面覆盖四个维度的 benchmark，多轮增量格式
- 揭示了当前 LLM 在选择性遗忘（丢掉无关信息）和测试时学习（从交互中持续更新信念）方面的系统性弱点

## Connection to Our Work

- **Critic 评估补充维度**：当前 Critic 只看 `score + violations → should_replan`。MemoryAgentBench 的四个维度可以直接作为 Critic 的补充评估：
  - **准确检索**：LLM 在做 DecisionFragment 时，是否正确引用了 PlanV2 的 turn_priorities？
  - **测试时学习**：开局后 LLM 是否根据对手的实际行为更新了策略假设？
  - **长程理解**：T3 的 DecisionFragment 是否还记得 T1 的开局布局？
  - **选择性遗忘**：LLM 是否被过期信息（如已死亡角色的状态）干扰决策？
- **对局 replay 分析**：可以用这四个维度回溯分析失败对局——是「忘了策略」还是「策略错了」？

## Critical Assessment

**Strengths**: 理论框架扎实（来自认知科学）；四维分类清晰可操作；多轮增量格式更真实。  
**Weaknesses**: 不是方法论文（只定义了 benchmark，没有给出解法）；对 GI TCG 的卡牌特有记忆需求（如手牌追踪、骰子记忆）没有覆盖。  
**Reproducibility**: Benchmark 可下载使用。
