# Vector Policy Optimization: Training for Diversity Improves Test-Time Search (VPO)

- **arXiv ID**: [2605.22817](https://arxiv.org/abs/2605.22817)
- **Authors**: Ryan Bahlous-Boldi, Isha Puri, Idan Shenfeld, Akarsh Kumar, Mehul Damani, Sebastian Risi, Omar Khattab, Zhang-Wei Hong, Pulkit Agrawal
- **Date**: 2026-05-21
- **Relevance**: ⭐⭐ (2/5) — LOW

## Summary

Proposes Vector Policy Optimization (VPO) as a replacement for scalar-reward GRPO training. Instead of optimizing a single reward, VPO trains for a vector of rewards to produce higher-entropy response distributions, enabling better inference-time search (like AlphaEvolve rollouts). LLMs trained with VPO show more diverse outputs that benefit test-time search procedures.

## Relevance to GI TCG

- VPO is a general LLM training technique, not game-specific
- Could theoretically improve diversity of LLM-generated deck analysis or action candidates, but the connection is indirect
- No immediate application to GI TCG pipeline — monitor for future if we adopt test-time search
