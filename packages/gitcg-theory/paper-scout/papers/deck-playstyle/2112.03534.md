# Deep Surrogate Assisted MAP-Elites for Automated Hearthstone Deckbuilding

- **arXiv ID**: [2112.03534](https://arxiv.org/abs/2112.03534)
- **Authors**: Yulun Zhang, Matthew C. Fontaine, Amy K. Hoover, Stefanos Nikolaidis (4 authors)
- **Date**: 2021-12-07
- **Venue**: arXiv preprint (cs.NE)
- **Citations**: Unknown
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — continuous behavior space for deck representation)

## Summary

研究如何高效生成高质量且多样化的卡牌游戏内容。之前的工作使用 MAP-Elites（Quality Diversity 算法）生成多样化的 Hearthstone deck 集合，但需要大量昂贵评估。本文提出用深度代理模型（deep surrogate）在线预测候选 deck 的对局结果来辅助 MAP-Elites。MAP-Elites 发现多样化数据集 → 改善代理模型 → 加速搜索。

## Key Contributions

- 深度代理模型加速 MAP-Elites deck 生成
- Online learning 的 surrogate model 与 QD 搜索协同
- **用连续行为空间 (behavior space) 表示 deck —— 而非离散 archetype**
- 在 Hearthstone 上实证：多样性（不同策略风格）和质量（高胜率）可兼得

## Connection to Our Work

- **连续行为空间是关键借鉴**：MAP-Elites 将 deck 映射到 behavior descriptor（如 "平均出伤速度"、"资源消耗量"、"回合数"）——这是一个天然的连续谱，不需要 aggro/midrange/control 标签。这正是我们在 GI TCG 中需要的替代方案。
- **与 CGT 的连接**：behavior descriptor 的维度可以设计为 CGT-relevant：cold-hot score、Number-probability、骰子利用率。CGT 的 Number/Non-number 分类器可以直接用作 behavior space 的一个轴。
- **Deck generation → Deck prior**：MAP-Elites 生成的多样化 deck 集合和它们的行为描述可以作为 deck prior 的初始化——不是"这副卡组是什么 archetype"，而是"这副卡组在行为空间中的坐标"。
- **与 llm-deck-analyzer 的对接**：可以用 replay 数据从 behavior space 中提取各卡组的实际坐标，替代当前无效的 planProfile (setupSpeed/tempoPush/longGameValue 等)。

## Critical Assessment

**Strengths**: 优雅的连续表示方法；QD 算法保证多样性；深度代理模型加速。
**Weaknesses**: Hearthstone specific；MAP-Elites 的训练成本仍然高；behavior descriptor 的设计需要 domain knowledge。
**Reproducibility**: Low-Moderate — 方法论描述清晰但需要 Hearthstone 环境和大量 GPU。
