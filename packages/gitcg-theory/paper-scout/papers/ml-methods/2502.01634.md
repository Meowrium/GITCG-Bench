# Online GBDT: In-Place Updates for Efficient Adding/Deleting Data

- **arXiv ID**: [2502.01634](https://arxiv.org/abs/2502.01634)
- **Authors**: Not extracted
- **Date**: 2025-02-03
- **Venue**: arXiv preprint (cs.LG)
- **Citations**: Very new
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — GBRL 的工程使能器)

## Summary

提出高效的 GBDT 在线学习框架，同时支持增量学习（添加新数据）和减量学习（删除/降权旧数据）。这是首个 work 在 GBDT 上同时实现 unified incremental 和 decremental learning。通过校正梯度更新和树结构修改来降低每次更新的计算成本。关键技术包括历史分裂的缓存和批量校正来更新叶节点分数。

## Key Contributions

- 首个 GBDT 的 unified incremental + decremental learning 框架
- In-place updates：不重训整棵树，仅修改受影响的分裂和叶子
- 历史分裂缓存：记住哪些分裂是历史最优的，新数据来时快速判断是否需要改
- 批量校正：累积一批更新后再改树结构，降低 per-sample 成本

## Connection to Our Work

- **GBRL 的工程基础**：GBRL 提出 GBDT 做 RL 的概念，但没说具体怎么高效地在线更新 GBDT——这篇补上了工程实现
- **减量学习对 RL 关键**：RL 中旧数据的价值衰减（behavior policy 变了，老样本已经不反映当前策略），decremental learning 让 GBDT 可以忘记过时样本
- **与 gi-ml 对接**：`train_lgbm_value.py` 和 `train_slot_linear_ranker.py` 当前是离线批训练。如果采用这篇的方法，可以在 self-play 过程中持续更新 GBDT，不需要每轮重新训练

## Critical Assessment

**Strengths**: 解决实际工程瓶颈；in-place updates 大幅降低计算成本；统合增删两种操作。
**Weaknesses**: 2025 年新论文，工业验证有限；需要修改底层 GBDT 库（不是直接换一个 pip install）。
**Reproducibility**: Moderate — 算法描述清晰，但需要改造 LightGBM/XGBoost 内部。
