## Abstract

Given a strategically complex board game, human players can quickly learn to devise strategies after playing a few rounds. Autonomous agents require similar capabilities in realistic interactive environments, yet existing agent benchmarks often fail to fully capture such strategic and evolving decision-making scenarios. We present PTCG-Bench, a benchmark built on the Pokémon Trading Card Game (PTCG) that evaluates LLM agents at two complementary levels: (1) their decision-making performance within a single complex environment, and (2) their ability to self-evolving through accumulated experience. We further include a modular harness ablation to better interpret agent performance without conflating it with model capability. Our experiments show that, although LLM agents can achieve non-trivial gameplay performance, sustained and stable self-evolution remains challenging, and performance is sensitive to harness design. We hope that PTCG-Bench will facilitate future research on harness-aware and self-evolving agents in realistic interactive environments.

## 1 Introduction

Games have long served as important testbeds for autonomous agents, driving progress from Atari, Go, StarCraft II to recent LLM agents in Minecraft and Diplomacy. More recently, Pokémon has attracted growing attention as a challenging domain for both competitive battling and open-ended RPG gameplay.

PTCG-Bench evaluates LLM agents in the Pokémon Trading Card Game along three dimensions:
1. **Decision-making** under imperfect information and long-horizon strategic interaction
2. **Self-evolution** through accumulated cross-game experience
3. **Harness design** contribution beyond backbone capability

## 2 Preliminary

### 2.1 Pokémon Trading Card Game

PTCG is a two-player, turn-based, zero-sum card game (60-card decks). Challenging for LLMs because it combines hidden information, stochastic card draws, dynamic legal actions, and long-horizon resource planning.

### 2.2 LLM Agent Formalization

Modeled as POMDP. Agent policy:
- a_t ~ π_{θ,η}(· | o_t, h_t)
- θ = LLM backbone, η = harness design
- J(θ,η) = E_π[Σ r_t]

## 3 PTCG-Bench

### 3.1 Benchmark Environment

- **Engine**: Custom Python PTCG engine for reproducible rule execution
- **Deck pool**: 5 competitive decks (aggressive, controlling, combo, attrition)
- **State/action**: Separates private/public/global state. Action space = parameterized game actions exposed through tool schemas

### 3.2 Agent-Environment Interface

Engine → observation → harness → prompt → LLM → structured action → parse & validate → execute

### 3.3 Longitudinal Evaluation Protocol

Multi-round evaluation: agents play sequences of games, update persistent state after each round (reflections, memories, prompts, skills). Tracks round-wise performance against fixed-policy anchors.

### 3.4 Modular Harness Architecture

Three key harness components that can be ablated:
- **H1**: Observation structure (structured state vs raw state)
- **H2**: Legal-action masking (engine-computed legal actions vs agent inference)
- **H3**: Context management (recent history vs current state only)

### 3.5 Evaluation Tournament

Two-stage design:
1. **Round robin**: Fixed agents play every other configuration → Glicko-2 ratings
2. **Anchored tournament**: Evolving agents play fixed anchor baselines → stable rating scale across rounds

### 3.6 Evaluation Metrics

1. **Glicko-2 rating** (primary): μ and φ
2. **Head-to-head win rate**
3. **Invalid action rate**
4. **Tool calls** (interaction cost)

## 4 Experiments

### 4.1 Experimental Setup

**LLM Backbones** (10 models, 5 families):
- Gemini 3.1 Pro / Gemini 3 Flash
- Claude Sonnet 4.6 / Claude Haiku 4.5
- DeepSeek V4 Pro / DeepSeek V4 Flash
- GPT-5.4 / GPT-5.4 Nano
- Qwen3.6 Plus / Qwen3.5 Flash

**Non-LLM references**: Random, Heuristic
**Matches**: M=5 games per pair → 330 games per tournament

### 4.2 Backbone Strategic Capabilities (RQ1)

**Key result**: 617 Glicko-2 point gap between strongest (Gemini 3.1 Pro: 1854) and weakest LLM (GPT-5.4 Nano: 1237).

- Frontier variants consistently outperform cost-efficient counterparts
- Cost ≠ performance (non-monotonic)
- PTCG-Bench rankings only weakly correlate with LiveBench, SWE-Bench Pro, GPQA → measures capabilities beyond static language understanding

### 4.3 Self-Evolution (RQ2)

**5 evolving baselines** (all on Qwen3.5-Flash):
- **Reflexion**: post-game free-form reflection
- **ExpeL**: lesson distillation across games
- **Long-Term Memory**: retrieval over stored episodes
- **Prompt Evolution**: revise strategy prompt
- **Skill Library Evolution**: structured modular skills

**Result**: None of the five mechanisms shows consistent monotonic improvement across 8 rounds. Ratings fluctuate, no evolving config reliably surpasses non-evolving baseline.

> "existing agents still struggle to extract reusable strategic knowledge from long-horizon, imperfect-information gameplay without dense rewards or verifiable ground-truth solutions"

### 4.4 Modular Harness Ablation (RQ3)

| Configuration | Struct. | Mask. | Hist. | μ | Δμ | Inv. Rate | Tool Calls |
|---------------|---------|-------|-------|------|------|-----------|------------|
| Full Harness | ✓ | ✓ | ✓ | 1726 | – | 3.3% | 78.8 |
| w/o Structured Obs | ✗ | ✓ | ✓ | 1693 | -33 (0.6×) | 5.2% | 68.4 |
| w/o Legal Action Masking | ✓ | ✗ | ✓ | 1608 | **-118 (2.1×)** | 15.9% | 86.7 |
| No History Context | ✓ | ✓ | ✗ | 1611 | **-115 (2.1×)** | 19.0% | 385.7 |
| Minimal Harness | ✗ | ✗ | ✗ | 1575 | -151 (2.7×) | 27.3% | 357.6 |

Harness design has substantial effect: removing legal-action masking or history drops rating by 2.1× the median adjacent-backbone gap!

### 4.5 Cross-Deck Generalization

Agent ranking largely preserved across all 5 decks → measured differences are not artifacts of a single mirror deck.

## 6 Conclusion

Current LLM agents can achieve meaningful gameplay performance, but accumulated experience does not yet reliably translate into stable performance gains. Harness design materially affects measured capability. PTCG provides a challenging testbed for self-evolving agents.
