- **Relevance Score**: ⭐⭐⭐⭐⭐ (5/5)

## Summary

Uses LLMs to translate natural language game rules and trajectories into executable Python **Code World Models** (CWMs): functions for state transition, legal move enumeration, termination checks, heuristic value functions, and inference functions for hidden states. These generated models serve as verifiable simulation engines for MCTS planning. Evaluated on 10 games (5 perfect info, 5 imperfect info, 4 novel). **Outperforms or matches Gemini 2.5 Pro** in 9/10 games.

## Key Contributions

- **LLM → executable world model**: Paradigm shift from prompting LLMs for direct moves to synthesizing verifiable game engines
- **Three-layer architecture**: State transition + termination + heuristic value function + inference (for imperfect info)
- **Verifiability**: Generated CWM is a formal specification; planners algorithmically enumerate valid actions avoiding illegal moves
- **Generalization**: LLM focuses on the meta-task of data-to-code translation, adapting to new games without retraining
- **Strategic depth**: Combines LLM semantic understanding with deep MCTS search

## Connection to Our Work

- **Direct applicability to GI TCG**: This is the closest existing work to what we want — an LLM that reads GI TCG rules and generates an executable game model + MCTS planner. The CWM approach could be adapted for GI TCG's complex rule system.
- **Deck prior integration**: The heuristic value function generated by the LLM could serve as a deck-conditioned prior for MCTS, complementing our GBDT ranker.
- **Imperfect information handling**: The inference function for estimating hidden states directly maps to opponent hand/deck modeling in GI TCG.
- **Code generation pipeline**: The "rules → code → planner" pipeline is a template for our LLM deck prior architecture.
- **Author network**: Multiple authors (Hennes, Lanctot, Gemp) also authored CSRO (2603.10098) — a connected research program on LLM-based game AI.

## Critical Assessment

**Strengths**: Elegant framework; strong empirical results across diverse games; verifiable and interpretable; excellent generalization.  
**Weaknesses**: Relies on LLM correctly generating the CWM (correctness is only "contingent"); tested on relatively simple games (compared to GI TCG); no competitive play against humans.  
**Reproducibility**: Moderate — 16-author DeepMind paper; code not explicitly released but methodology is well-documented.
