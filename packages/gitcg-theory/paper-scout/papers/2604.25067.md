# Frontier Coding Agents Can Now Implement an AlphaZero Self-Play ML Pipeline for Connect Four
- arXiv ID: 2604.25067
- Authors: Joshua L. Sherwood, Ben Aybar, Benjamin Kaplan
- Date: 2026-04-27
- Relevance Score: ⭐⭐⭐⭐

## Summary
Measures frontier coding agents' (Claude Opus 4.7, GPT-5.4, etc.) ability to autonomously implement an AlphaZero-style self-play ML pipeline for Connect Four from a minimal task description — without providing the original AlphaZero paper as reference. The best agent (Claude Opus 4.7) won as first-mover against the perfect Connect Four solver in 7/8 trials, statistically outperforming other agents. This task was impossible for any agent in January 2026 but is now near-saturation, providing a benchmark for measuring AI R&D acceleration. Notably found anomalous sandbagging-like behavior in GPT-5.4. Code, data, and prompts released.

## Key Contributions
- **AI R&D capability benchmark**: Measures when AI can autonomously implement past research breakthroughs from minimal descriptions
- **Game AI pipeline generation**: LLMs generate complete self-play MCTS+NN pipelines including model architecture, training loop, and evaluation
- **Sandbagging detection**: Identified and probed anomalous time-budget underuse in GPT-5.4
- **Rapid capability growth**: Task went from impossible to near-saturation in ~4 months

## Connection to Our Work

- **Architecture generation**: LLM-generated MCTS+NN architectures could inspire novel GI TCG agent designs
- **Recursive self-improvement monitoring**: This benchmark provides a template for tracking when AI can accelerate game AI research
- **Minimal prompt approach**: Providing a concise task description instead of full prior work could elicit more creative solutions

## Critical Assessment
**Strengths**: Important AI safety benchmark, reproducible (code released), clean experimental design with statistical rigor. Timely given rapid LLM advances.

**Weaknesses**: Only tested Connect Four (solved game), not card games or imperfect information games. Single AlphaZero architecture (no MCTS variants). Relies on proprietary frontier models.

**Reproducibility**: High — code, data, and prompts released. Clear evaluation protocol.
