# Tree of Thoughts: Deliberate Problem Solving with Large Language Models

- **arXiv ID**: [2305.10601](https://arxiv.org/abs/2305.10601)
- **Authors**: Shunyu Yao, Dian Yu, Jeffrey Zhao, Izhak Shafran, Thomas L. Griffiths, Yuan Cao, Karthik Narasimhan (Princeton, Google DeepMind)
- **Date**: 2023-05-17
- **Venue**: NeurIPS 2023
- **Citations**: Very High (landmark paper)
- **Relevance Score**: ⭐⭐⭐ (3/5 — 决策树的搜索增强，对 MCTS 有互补价值)

## Summary

LLM 推理被限制在 token 级、从左到右的决策过程，在需要探索和战略前瞻的任务中不足。Tree of Thoughts (ToT) 泛化 Chain-of-Thought，允许 LLM 在推理路径上做**树搜索**——考虑多个不同推理分支、自评估选择、必要时回溯。在 Game of 24（数学推理）上成功率从 CoT 的 4% 提升到 74%。

## Key Contributions

- **Thought 作为搜索单元**：每个 Thought 是连贯的文本片段（而非单个 token），在此粒度上做 BFS/DFS
- **Self-Evaluation**：LLM 自评估每个 Thought 的 promissingness，决定是否继续探索或回溯
- **搜索策略可配置**：BFS（广度优先）适合分支少的任务，DFS（深度优先）适合需要深度规划的任务
- 在创意写作和填字游戏上也验证有效

## Connection to Our Work

- **决策分支探索**：当前 Resolver 的线性打分可以在简单局面选出最优，但在复杂局面（多步连锁反应）中可能需要搜索。ToT 的模式是：LLM 生成多个候选 DecisionFragment → 自评估 promisingness → 选最优路径。
- **与 MCTS 互补**：你的 MCTS + GBDT 做的是 game tree 搜索。ToT 做的是 LLM reasoning tree 搜索。两者可以正交叠加——MCTS 处理 game state 搜索，ToT 处理 decision reasoning 搜索。
- **低优先级**：对于 GI TCG 的单步决策，ToT 的搜索开销可能大于线性 Resolver 的收益。但对「多步连锁决策」（如 3 步 combo），ToT 的 BFS 可能比固定 candidate_policies 更灵活。

## Critical Assessment

**Strengths**: 搜索增强推理、self-evaluation 机制、验证了多种搜索策略。
**Weaknesses**: 多次 LLM 调用成本高；对单步决策收益有限；evaluation 质量依赖 LLM 自评准确度。
**Reproducibility**: 模式清晰但调用次数多。
