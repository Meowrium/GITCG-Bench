# Evolving the Hearthstone Meta

- **arXiv ID**: [1907.01623](https://arxiv.org/abs/1907.01623)
- **Authors**: Fernando de Mesentier Silva, Rodrigo Canaan, Scott Lee, Matthew C. Fontaine, Julian Togelius, Amy K. Hoover (6 authors)
- **Date**: 2019-07-02
- **Venue**: arXiv preprint (cs.AI, cs.NE)
- **Citations**: Unknown
- **Relevance Score**: ⭐⭐⭐ (3/5 — balancing methodology, not archetype definition)

## Summary

讨论修改现有卡牌属性对 Hearthstone 策略的影响。通过分析不同 deck 之间的 matchup win rate，比较修改前后的表现。使用进化算法搜索最小改动量下使所有 deck 接近 50% 胜率的卡牌属性组合。提出并评估用于选择平衡目标卡牌的启发式指标。

## Key Contributions

- 进化算法驱动的自动化游戏平衡
- 多目标优化：同时最小化 win rate 偏差和卡牌改动量
- 基于 matchup matrix 而非 archetype label 的评估框架
- 平衡目标卡牌选择的启发式指标

## Connection to Our Work

- **Matchup matrix 思维**：他们用 deck × deck 的胜率矩阵而非 archetype 标签来建模——这和我们的发现一致。在 GI TCG 中，matchup matrix 比 "这副卡组是 midrange" 更有信息量。
- **平衡性指标**：他们提出的卡牌选择启发式可能适用于 GI TCG 的 deck prior weight 调整——哪些卡对 meta 平衡影响最大？
- **进化算法**：如果我们在 GI TCG 中做 deck generation 或 deck prior optimization，进化算法是一个候选方法。

## Critical Assessment

**Strengths**: 实用导向；多目标优化框架；Hearthstone 真实数据验证。
**Weaknesses**: 聚焦于游戏平衡 (balancing) 而非 deck classification；Hearthstone specific。
**Reproducibility**: Low-Moderate — 方法论清晰但依赖 Hearthstone 特定数据和 API。
