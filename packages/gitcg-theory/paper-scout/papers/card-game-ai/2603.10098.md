# Code-Space Response Oracles: Generating Interpretable Multi-Agent Policies with LLMs

- **arXiv ID**: [2603.10098](https://arxiv.org/abs/2603.10098)
- **Authors**: Daniel Hennes, Zun Li, John Schultz, Marc Lanctot (DeepMind)
- **Date**: 2026-03-10
- **Relevance**: ⭐⭐⭐ (3/5) — MEDIUM

## Summary

Replaces black-box RL oracles in PSRO (Policy-Space Response Oracles) with LLM-generated code policies. Three oracle variants: zero-shot, iterative refinement, and AlphaEvolve (distributed LLM-based evolution). Produces interpretable, human-readable policies while maintaining competitive performance.

## Relevance to GI TCG

- Connected to Code World Models (2510.04542) — same author group at DeepMind
- PSRO framework is directly relevant to multi-agent game theory for GI TCG
- LLM code generation for game policies is complementary to LLM deck prior
- AlphaEvolve distributed evolution may scale to complex card games
