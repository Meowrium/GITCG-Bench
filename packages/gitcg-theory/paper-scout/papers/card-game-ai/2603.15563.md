---

## 核心内容

基于宝可梦的 **双赛道** benchmark：

| Battling Track | Speedrunning Track |
|---------------|-------------------|
| 宝可梦对战 | 宝可梦 RPG 速通 |
| 部分可观测 + 博弈推理 | 长程规划 + 序贯决策 |
| 2000万+ 对战 trajectory | 开源多 agent 编排系统 |
| Heuristic/RL/LLM baseline | LLM harness 方法比较 |

**NeurIPS 2025 比赛**: 100+ 队伍参赛。关键发现 — **Pokémon battling 与传统 LLM benchmark 几乎正交**，测的是现有 suite 没覆盖的能力。

## 与 PTCG-Bench 对比

| | PokeAgent Challenge | PTCG-Bench |
|---|---|---|
| 游戏 | Pokémon (battle + RPG) | Pokémon TCG |
| 对战类型 | 宝可梦本体对战 (属性克制/技能) | 卡牌对战 (资源管理/牌组构建) |
| 数据规模 | 2000万+ trajectory | 330 场 tournament |
| Self-evolution | ❌ | ✅ 核心 |
| Harness | 部分 ablation | ✅ 系统化 H1/H2/H3 |
| 赛事 | NeurIPS 2025 比赛 | 无 |

## 对 GI TCG 参考价值
- Battling Track 的 partial observability + game-theoretic reasoning 与 TCG 高度相似
- 2000万 trajectory 规模 — 如果我们有 GI TCG replay 数据，可以做类似的分析
- 「Pokémon 与标准 benchmark 正交」—— 暗示 GI TCG benchmark 也会有独特价值
- Speedrunning Track 的多 agent 编排系统可参考
