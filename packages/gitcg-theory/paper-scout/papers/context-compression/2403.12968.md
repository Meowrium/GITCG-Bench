# LLMLingua-2: Data Distillation for Efficient and Faithful Task-Agnostic Prompt Compression

- **arXiv ID**: [2403.12968](https://arxiv.org/abs/2403.12968)
- **Authors**: Huiqiang Jiang, Qianhui Wu, Chin-Yew Lin, Yuqing Yang, Lili Qiu (Microsoft)
- **Date**: 2024-03-19
- **Venue**: arXiv preprint (cs.CL)
- **Citations**: High (notable paper)
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — GameState→LLM 文本的自动压缩)

## Summary

把 prompt 压缩建模为 **token 分类问题**（保留 vs 丢弃每个 token）。用 data distillation 从 LLM 中提取压缩知识：LLM 标注每个 token 的重要性 → 小模型（Transformer encoder）学习压缩。与基于信息熵的方法不同：(1) 利用 full bidirectional context（而非 unidirectional），(2) 显式对齐压缩目标（而非依赖信息熵的代理指标）。task-agnostic——不依赖具体任务。

## Key Contributions

- **Data Distillation for Compression**：用大 LLM 自动标注 token 重要性 → 训练小压缩模型，无需人工规则
- **Bidirectional Context**：压缩器使用 full bidirectional context，比 causal LLM 的信息熵度量更准确
- **Faithfulness Guarantee**：token 分类保证压缩后的文本是原文的子集（可解释、可验证）
- **2-5x 压缩率**，同时保持下游任务性能

## Connection to Our Work

- **TurnDigest 文本再压缩**：当前 `get_turn_digest_v1` 产出的文本由人工设计字段决定。可以在 TurnDigest 文本输出后套一层 LLMLingua-2 做自动压缩——减少 token 但不丢关键信息。
- **对手状态描述压缩**：`opponent_summary` 字段可能包含 LLM 不需要的细节（如精确 HP 数值 vs "低血量" 对决策无差异）。LLMLingua-2 可以自动学习哪些对手信息对决策有价值。
- **候选动作描述压缩**：`candidate_actions` 的 `notes` / `tags` 字段可以走压缩——保留"高伤害+火附着"、丢弃冗余描述。
- **不依赖 API**：LLMLingua-2 是本地小模型，不需要额外 API 调用，可以在 MCP server 层或 standalone bridge 层嵌入。

## Critical Assessment

**Strengths**: 成熟方案、社区活跃、微软出品；task-agnostic 适合游戏多变状态；本地运行无 API 成本。  
**Weaknesses**: 压缩是 extractive（只能删 token，不能改写）——对游戏状态的文本描述，有时「改写」比「删 token」更有效（SUPO 是改写路线）；需要对 GI TCG 的 state 文本做适配。  
**Reproducibility**: 高——开源模型、文档完善。
