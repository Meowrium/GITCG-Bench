### 2. Chrustowski & Duch — Policy-Based RL for Card Game "Thousand" (2025) ⭐⭐⭐⭐

**Source:** Semantic Scholar (no arXiv ID found)  
**Date:** 2025-02-17  

**TL;DR**: Self-learning agent for the trick-taking card game "Thousand" (popular in Eastern Europe). Policy-gradient approach handles the game's complex bidding system and dynamic gameplay. Addresses vast state space and strategic complexity that make MCTS/CFR challenging.

**Why it matters**: Trick-taking card games share structural properties with GI TCG's round-by-round play. The bidding phase maps to GI TCG's deck selection/mulligan decisions. Policy-gradient approach offers an alternative to tree search for massive action spaces.

**Connection to Our Work**: The policy-gradient approach to bidding could inform our deck selection prior. The trick-taking structure with trump suits is analogous to GI TCG's elemental reaction system where certain card types dominate others.

**Action**: Evaluate policy-gradient as alternative to MCTS for GI TCG action selection in high-branching-factor states.

### 3. Cutajar & Bajada — Mastering Jaipur with Self-Play RL (2023) ⭐⭐⭐⭐

**Source:** Semantic Scholar (no arXiv ID found)  
**Date:** 2023  

**TL;DR**: Zero-knowledge self-play reinforcement learning with action masks for the two-player trading card game Jaipur. Agent learns from scratch without human demonstrations or heuristic features.

**Why it matters**: Jaipur is a market-based card game involving resource trading and set collection — structurally closer to GI TCG than trick-taking games. The zero-knowledge self-play approach demonstrates pure RL can master card games. Action masks are key for handling legal move constraints.

**Connection to Our Work**: Zero-knowledge setup mirrors our goal of training GI TCG agents without demonstration data. Action masking methodology is directly applicable to GI TCG's constrained action space (dice costs, elemental requirements).

**Action**: Study action mask formulation for GI TCG. Consider Jaipur as a simpler intermediate testbed before full GI TCG.

### Critical Finding: all: Search is Fundamentally Broken

Confirmed across 3 consecutive weeks (W24, W25, W26): arXiv's `all:` search with date sort returns the **full daily cs.AI listing**, not papers matching the search terms. This is not a rate-limiting issue — it's a search quality issue. Even with successful queries, 96%+ of results are noise.

**Example from W26**: "Monte Carlo tree search card game" returned papers about Monte Carlo methods in physics, not card game MCTS. "Card game benchmark reinforcement learning" returned the standard cs.AI daily listing (robotics, CV, NLP).

Semantic Scholar succeeded where arXiv failed:
- **Relevance-based search** actually returns card-game-relevant papers
- **Broader index** includes non-arXiv venues (conferences, theses)
- **Rate limiting exists** but appears less aggressive — we got 2 queries before 429

**However**, S2's free tier is also rate-limited (1 req/sec without API key, 100/sec with key). We need to either:
1. Apply for an S2 API key (free, fast approval)
