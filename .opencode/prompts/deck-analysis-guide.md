# 七圣召唤 AI 对战 — 卡组分析指南

> 提炼自 `@gi-tcg/llm-deck-analyzer` 包的 SKILL.md，仅保留对战 AI 需要的部分。

## 开局必须做的事

对战开始后、进入决策循环前，完成以下分析（**只做一次**，不要每回合重复）：

1. 调用 `get_player0_deck` 和 `get_player1_deck` 获取双方卡组代码
2. 调用 `analyze_deck` 分析己方卡组（获得角色、关键卡牌、强度、获胜方式、展开路线）
3. 调用 `analyze_matchup` 分析双方对局（获得优势方向、关键互动、双方策略、预测胜率）
4. 根据分析结果制定整体对局策略，后续每个决策回合参考此策略

## 卡牌效果准确性约束（必读）

**你必须严格依据 tool 返回结果中的卡牌描述来理解效果，严禁凭记忆编造。** 以下是最容易出错的卡牌：

| 卡牌名 | ❌ 常见幻觉 | ✅ 实际效果 |
|--------|------------|------------|
| 星天之兆 | 莫娜的天赋牌 | **事件牌**，使出战角色获得1点充能，2无色费用 |
| 本大爷还没有输！ | 角色血量低时触发 | **战斗行动**，我方角色被**击倒**后才能打出，生成1万能+1充能 |
| 赌徒的耳环 | 击杀后获得2骰 | 敌方被击倒时，若附属角色为**出战角色**，生成2万能（整局限3次） |
| 唐杜尔烤鸡 | 单个角色E+2 | **全体角色**下次E伤害+2（战斗料理） |
| 交给我吧！ | 免费切人 | **快速行动**，下次切换视为快速行动（一次性，与莫娜被动不同） |
| 换班时间 | 免费切人 | 下次切换少花1个元素骰 |
| 送你一程 | 消灭召唤物 | 使敌方召唤物**可用次数-2** |
| 白垩之术 | 转移1点充能 | 从最多2个后台角色各转移1点充能到出战角色 |
| 提米 | 3回合后抓牌 | 初始已有1只鸽子，2回合后激活 |

**通用规则：**
- `[天赋]` vs `[事件]` 是不同的卡牌类别，不可混淆
- `[战斗行动]` 打出后回合交给对方；`[快速行动]` 不交出回合
- `[料理]` 每回合限1张；`[秘传]` 全场限1张
- 角色被动技能 ≠ 卡牌效果（如莫娜「虚实流动」≠「交给我吧！」）

## 分析结果的使用

`analyze_deck`（增强版）返回的 JSON 包含以下结构：

### baseline（启发式基线）
旧格式的启发式分析，作为参考起点。**不建议直接照搬**，应基于 deckContext 自行推理。

### deckContext（完整卡组上下文）
- `characters[]`：角色完整信息（name/elements/weapon/hp/maxEnergy/skills[].type/description/playCost）
- `cards[]`：卡牌完整信息（name/type/subtype/description/playCost/tags）
- `cardCounts[]`：重复卡牌（用于换牌决策）
- `entityDescriptions{}`：衍生物/召唤物/战斗状态效果
- `analysis{}`：多项分析数据
  - `skillEfficiency[].topSkills[]`：技能经济效率（dmgPerDie/estimatedDamage）
  - `comboClock[]`：组合技爆发窗口（置信度/最早回合/所需卡牌）
  - `resourceCycles[]`：跨卡牌资源循环（净骰/净牌/可重复）
  - `drawEstimate`：每回合抽牌期望
  - `zonePressure`：支援区压力分析
  - `freeCards[]`：可降费至免费打出的牌

### MatchupAnalysis（对局分析）
- `baseline`：对局启发式基线
- `deckAContext` / `deckBContext`：双方完整卡组上下文
- 注意：`analyze_deck` 的 deckContext 更详细（含 entityDescriptions/analysis），matchup 的 deckContext 更精简。

### 策略提取要点

1. **开局角色选择**：参考 `commonLines` 中的展开路线决定首发，优先考虑能量经济和元素共鸣
2. **关键卡牌优先级**：手牌中有 `keyCards` 列出的卡牌时优先保留（换牌阶段）
3. **对局节奏**：根据 matchup 的 `strategy` 决定快攻/站场/控制节奏
4. **威胁识别**：记住对手 `keyCards` 中的卡牌，预判对方可能的展开

## 角色技能与衍生物联动

分析结果中可能包含角色的技能列表和衍生物信息。需要注意：

- 角色的E/Q/被动可能生成**召唤物**或**战斗状态**（如凝光璇玑屏、水形幻人半幻人），这些效果应纳入整体策略
- 衍生物标签：`[角色阵亡后保留]`（不依赖角色存活）、`[减伤]`、`[护盾]` 等影响战术判断
- 生成手牌（如刻晴雷楔、丝柯克虚境裂隙）可能被初始牌组中的减费牌覆盖

## 禁止事项

- 不要在分析中输出强度数字评分（如 "7.5/10"）
- 不要空口估计具体胜率百分比（可以说"对快攻偏劣势"，不能说"胜率约55%"）
- 不要对未在分析结果中出现的卡牌做具体效果断言
