# Think Twice, Act Once: Verifier-Guided Action Selection For Embodied Agents (VegAS)

- **arXiv ID**: [2605.12620](https://arxiv.org/abs/2605.12620)
- **Authors**: Nishad Singhi, Christian Bialas, Snehal Jauhri, Vignesh Prasad, Georgia Chalvatzaki, Marcus Rohrbach, Anna Rohrbach
- **Date**: 2026-05-12
- **Venue**: arXiv preprint
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — 测试时 verifier 引导的 action selection)

## Summary

提出 VegAS（Verifier-Guided Action Selection），测试时框架：采样多个候选动作 → 用生成式 verifier 选出最可靠的。关键发现：**直接用 off-the-shelf MLLM 当 verifier 无效**，需要用 LLM 驱动的数据合成策略自动构建多样化失败案例来训练 verifier。在 Habitat 和 ALFRED 环境上实现 36% 相对增益。

## Key Contributions

- 采样 ensemble 候选动作 → verifier 筛选（而非简单多数投票）
- 发现 naive verifier（直接用 LLM 评估）**无效果**——必须用合成失败数据训练
- 自动构建多样化 curriculum of failure cases
- 最困难的 multi-object long-horizon 任务上 36% 相对提升

## Connection to Our Work

- **"Think Twice, Act Once" 范式**：与 self-consistency 类似但不依赖多数投票——用专门训练的 verifier 评估每个候选
- **Naive verifier 无效的发现**：如果直接在 GI TCG 用 LLM 做 action verifier（"这个动作好不好？"），可能也无效——需要 domain-specific 训练数据
- **OOD 鲁棒性**：GI TCG 的跨卡组场景就是 OOD——VegAS 的方法论有参考价值

## Critical Assessment

**Strengths**: 36% 相对提升很显著、verifier 机制比纯投票更精细、证明了 naive verifier 无效（重要教训）。

**Weaknesses**: 需要训练 verifier（不是纯 test-time）、embodied agent 场景与 TCG 有距离、2026 年新论文。

## Action Items
