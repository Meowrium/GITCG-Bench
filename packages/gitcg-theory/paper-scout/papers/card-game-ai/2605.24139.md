# MAPLE: Multi-State Aggregated Policy Evaluation for AlphaZero in Imperfect-Information Games
- **arXiv ID**: 2605.24139
- **Authors**: Qian-Rong Li, Hung Guei, I-Chen Wu, Ti-Rong Wu
- **Date**: 2026-05-22
- **Relevance Score**: ⭐⭐⭐⭐

## Summary
MAPLE extends AlphaZero-style reinforcement learning to imperfect-information games (IIGs) by addressing the core difficulty: the agent doesn't observe the true game state, only an information set. Existing approaches have a tradeoff — Perfect Information Monte Carlo (PIMC) determinizes the game but suffers from strategy fusion (treating different opponent hands as the same state), while Information Set MCTS (IS-MCTS) is computationally expensive with neural networks. MAPLE bridges this gap by aggregating policy and value evaluations from multiple sampled world states within a single search tree, using a Siamese-based sampling strategy to select informative states from the information set. Tested on Phantom Go and Dark Hex, MAPLE achieves Elo improvements of +291 and +136 over PIMC-based AlphaZero baselines.

## Key Contributions
- Novel tree search method that aggregates multi-state evaluations while maintaining controllable computational cost
- Siamese-based informative state sampling from the information set (not random determinization)
- First practical bridge between PIMC (cheap but flawed) and IS-MCTS (accurate but expensive) for AlphaZero IIG training
- Significant Elo gains on standard IIG benchmarks (Phantom Go, Dark Hex)
- Maintains compatibility with AlphaZero's neural architecture (single policy/value network)

## Connection to Our Work
**Directly applicable to GI TCG MCTS design.** GI TCG is an imperfect-information game where the opponent's hand and deck are hidden. Our current MCTS approach must handle this uncertainty:
- MAPLE's multi-state aggregation within a single search tree is precisely the type of mechanism we need for our MCTS+GBDT+LLM pipeline
- The Siamese sampling strategy could inform how we sample opponent hand/deck hypotheses during search
- The controllable computational cost is crucial — GI TCG needs real-time or near-real-time inference
- However, MAPLE is tested only on deterministic-outcome IIGs (board games), not stochastic card games — the extension to card game random draws is non-trivial
- MAPLE still uses AlphaZero's MCTS, not IS-MCTS — it's a "halfway" approach that may hit limits in GI TCG's fully hidden state space

## Critical Assessment
**Strengths:**
- Elegant solution to the PIMC/IS-MCTS tradeoff
- Significant empirical gains on established benchmarks
- From strong research group (Wu lab at Academia Sinica — experienced in game AI, including Mahjong/Imperfect info)

**Weaknesses:**
- Only tested on board games (Phantom Go, Dark Hex) — no card game experiments
- Still relies on determinization (multiple samples), which may be insufficient for GI TCG's large hidden state space (opponent's entire deck + hand)
- No comparison against full IS-MCTS with neural nets
- Single paper, not yet peer-reviewed

**Reproducibility:** Likely good — Wu lab has strong track record of releasing code (e.g., their previous Mahjong work)
