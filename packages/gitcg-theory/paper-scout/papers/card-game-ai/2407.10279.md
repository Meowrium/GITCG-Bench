## Summary

Modifies the Deep Monte Carlo (DMC) algorithm framework to produce a neural network that simultaneously estimates win rates and expectations. Uses expectation-based action space pruning and win-rate-based strategy generation. The model handles the full Doudizhu game pipeline — both bidding and cardplay — in the actual game environment. Achieves SOTA among publicly available Doudizhu models.

## Key Contributions

- **Unified bidding + cardplay**: End-to-end AI that handles both phases, unlike DouZero which simplified the environment
- **Dual-head neural network**: Simultaneous win rate + expectation estimation for action pruning
- **Real environment training**: Trained in actual Doudizhu rules, not a simplified variant
- **Architecture innovation**: Expectation-guided action space reduction for computational efficiency

## Connection to Our Work

- **Bidding ↔ Deck selection analogy**: Doudizhu's bidding phase (deciding whether to be landlord) is structurally similar to GI TCG's deck selection / character choice phase. AlphaDou's unified approach could inform our end-to-end pipeline.
- **Deep MC methodology**: Both AlphaDou and DanZero use Deep Monte Carlo — a close cousin of MCTS. Understanding their DMC variants helps us design better MCTS for GI TCG.
- **Action space pruning**: Expectation-based pruning for large action spaces is directly applicable to GI TCG's complex action enumeration.
- **Competition/cooperation dynamics**: Doudizhu's 1v2 landlord-farmer dynamic involves mixed cooperative-competitive reasoning relevant to GI TCG's team dynamics.

## Critical Assessment

**Strengths**: Unified pipeline design; trained on real rules; strong empirical results.  
**Weaknesses**: Only 2 authors; limited citation count; Doudizhu-specific architecture may not generalize easily.  
**Reproducibility**: Low-moderate — methodology described but no public code repository mentioned.
