# 对局数据欠采样分析：结论偏差修正

> 分析对象：`packages/gitcg-theory/replay-hidden-constraints-v2.md` 中基于 62 场 compact 对局得出的 P1-P9 约束
> 数据来源：`packages/gi-agent/output/iter-training/iter-265/replay-logs-baseline`
> 训练脚本：`packages/gi-agent/benchmark.training-v3.json`
> 对局配置：`iter-265/self-play-config-baseline.json`

---

## 一、样本偏差的来源

### 1.1 双方策略不平等

`replay-logs-baseline` 中的对局来自 `self-play-config-baseline.json`，其中：

- **sideA**（P0）：`gi-ml-runtime`，使用迭代的训练模型（iter-265，加载了 iter-261 的 ranker 和 iter-167 的 value/qvalue），`temperature=1.5`，`qValueWeight=1.5`
- **sideB**（P0/P1）：`baseline`，启发式策略，`temperature=1.2`，`adaptiveProfile=true`

**关键发现：这不是同一策略的镜像对弈。** sideA 是一个基于机器学习模型的策略，sideB 是一个纯启发式策略。之前 v2 文档中"P0与P1用的是同一agent"的假设不成立。

### 1.2 sideA 恒为 P0

由于 `sideA` 始终是 P0 侧（先手），本场数据中 P0 实际上是**更强的训练模型**，而 P1 是**更弱的启发式策略**。

这与之前分析的结论完全相反——v2 文档认为"P1（后手）胜率 87.5% 是因为后手优势"，但实际上：

| 文件名后缀 | winner含义 | 实际含义 |
|-----------|-----------|---------|
| `-p0` | P0 胜 | **训练模型（更强）胜 |
| `-p1` | P1 胜 | **启发式策略（更弱）胜 |
| `-draw` | 平局 | 平局 |

重新统计：在 62 场对局中，56 场以 `-p1` 结尾，2 场以 `-p0` 结尾，4 场（原文说5场，实际看文件名）以 `-draw` 结尾。由于 sideA（训练模型）恒为 P0，这意味着**启发式策略（P1）赢得了 87% 的对局，训练模型（P0）只赢了 2 场**。

### 1.3 基准配置中的策略不对等

benchmark 中每个 matchup 的 `sideA` 和 `sideB` 配置：
```json
"sideA": { "name": "baseline-a", "kind": "baseline", "options": { "endTurnPenalty": 5 } },
"sideB": { "name": "baseline-b", "kind": "baseline", "options": { "endTurnPenalty": 5 } }
```

benchmark 本身是 baseline vs baseline 的对称配置，**但 replay-logs-baseline 来自 self-play-config-baseline.json**，它覆盖了 benchmark 配置：
- sideA 被替换为 `gi-ml-runtime`（训练模型）
- sideB 被替换为 `opponent-heuristic`（启发式对手，`adaptiveProfile=true`）

因此数据中的双方策略**不仅在模型层面不对称，在类型层面也不对称**：一方是 ML 模型，另一方是启发式规则。

### 1.4 matchup 不对称

benchmark 中包含 8 个镜像对局（每套卡组 vs 自身）× 10 场 + 56 个非镜像对局 × 6 场 = 80 + 336 = 416 场总对局。但 `replay-logs-baseline` 的 `maxGamesPerMatchup=1`，只保留了每 matchup 1 场的回放。

**每 matchup 只保留 1 场**回放，这意味着：
- 8 个镜像对局每组只有 1 场（如果真打10场里只留1场的话差异巨大）
- 每个非镜像 matchup 也只有 1 场
- 总共 62 场 / 约 64 个 matchup ≈ 每 matchup 约 1 场

**单场数据的方差极大**，无法可靠推断任何胜率结论。

## 二、对 P1-P9 约束的逐条修正

### P1（后手结构性优势）—— **结论不成立**

**原始结论**："P1 胜率 87.5%，先后手产生系统性 V(s) 偏移"

**修正**：87.5% 的"P1 胜率"实际是"启发式策略（sideB）胜率"。由于训练模型恒为 P0（先手），这个数据反映的是**启发式策略比训练模型更强**，而非先后手优势。先后手效应完全被策略能力差异混淆。

要从这个数据中分离先后手效应，需要：
1. 同一策略的镜像对弈数据（同模型 P0 vs 同模型 P1）
2. 或至少 sideA/sideB 交替做 P0/P1 的平衡数据

当前数据无法支持"后手结构性优势"的任何结论。

### P2（行动质量鸿沟）—— **需重新归因**

**原始结论**："P0有效行动密度低50%，先手位置迫使骰子保留"

**修正**：P0 是训练模型，它的行动质量低不是因为"先手位置被迫保留骰子"，而是因为**训练模型的决策质量本身就低于启发式策略**。P0 更多地选择过牌/无效行动，是模型能力问题，不是先后手位置问题。

启发式策略的优势在于它可能硬编码了某些合理的启发式规则（如优先使用技能、优先切人触发反应等），而训练模型在这些基础决策上还不如启发式。

### P3（首杀-雪崩时间加速）—— **方向正确但归因模糊**

**原始结论**："首杀触发三重加速，信息+约束+恢复窗口同时坍缩"

**修正**：首杀后的雪崩效应是否真实存在，需要区分"强的对手打弱对手自然连胜"和"首杀本身引发的策略级联"。在当前数据中，由于双方策略本身就是不对称的（启发式更强），首杀大概率发生在弱方（训练模型侧），后续雪崩可能只是强弱差距的自然延续，而非首杀触发的特殊机制。

理论框架中对3→2坍缩的分析仍然是有价值的（H7），但当前数据无法独立验证P3。

### P4（结构性不可竞争区间）—— **卡组差异被策略差异混淆**

**原始结论**："某些配对从开局就无胜率>0路径（4场零封）"

**修正**：零封数据的正确解读是"启发式策略用某些卡组可以零封训练模型"，而非"某些卡组配对结构上不可竞争"。零封可能源于：
1. 启发式策略对这些卡组的处理更好
2. 训练模型对某些元素组合无法有效响应
3. 随机性（单场数据无法排除骰子运气因素）

结构性不可竞争是否存在，需要在**同策略镜像对弈**中验证同卡组的胜负比，当前数据无法排除"策略质量问题"的解释。

### P5（时间压力非对称性）—— **适用性存疑**

**原始结论**："15回合上限对P0是失败倒计时"

**修正**：在当前数据中，P0是训练模型，6场平局中P0处于劣势是训练模型本身弱的表现。如果高质量策略对弈，15回合的时间压力是否对先手不利，需要同策略数据验证。

时间压力的双向非对称性（框架文档 H6 中已讨论的"快攻需要加速、控制需要拖平"）是成立的，但"P0在平局中更亏"的结论在当前数据下不能归因于先后手。

### P6（死亡四重惩罚）—— **成立但需标注数据来源限制**

**原始结论**："角色死亡伴随能量归零+附着清除+位置失控"

**修正**：这是引擎硬编码规则的策略层推论，不受采样偏差影响。角色死亡确实伴随四重惩罚。但P6中"94.8%的首杀发生在P0侧"的统计需修正——这个数据反映的是训练模型（P0）更弱，而非先手更易被首杀。

### P7（切人策略分化）—— **需重新归因**

**原始结论**："P0切人70%防御性，P1切人55%主动性"

**修正**：这个差异反映的是**训练模型和启发式策略在切人决策上的质量差异**，而非先后手位置的策略分化。训练模型可能没有学到主动切人触发反应的策略，所以切人更多是被动的。

### P8（投资-时间不对称）—— **方向正确但统计偏差**

**原始结论**："P0多投资支援牌但活不到兑现"

**修正**：P0（训练模型）可能倾向于打出支援牌是因为模型学到的策略偏好铺设装备（这在ML模型中常见——装备牌的短期reward可能更稳定），而非因为先手位置的策略劣势。方向是合理的（长线投资需要存活时间来兑现），但数据归因不正确。

### P9（伤害集中度效应）—— **成立但需排除策略混淆**

**原始结论**："伤害集中度比总量更重要"

**修正**：理论方向成立（击倒的阈值效应是真实的游戏机制），但数据中的观察——P1（启发式策略）的伤害更集中——可能是启发式策略本身的特性（可能硬编码了元素反应连招），而非先后手位置导致的伤害分布差异。

## 三、哪些结论仍然成立

尽管采样偏差严重，以下结论**不受策略不对称影响**，仍然成立：

| 编号 | 结论 | 为什么仍然成立 |
|------|------|-------------|
| P6 | 死亡伴随能量归零+附着清除+位置失控 | 这是引擎规则的推论，不依赖统计结论 |
| P9 | 击倒的阈值效应使伤害集中度优于分散伤害 | 这是游戏机制的理论推论，数据仅作示意图 |
| H1-H8 | 全部仍然成立 | 这些约束只依赖游戏机制，不依赖策略对比 |

以下结论**方向可能成立但当前数据无法证实**，需要同策略镜像数据重新验证：

| 编号 | 结论 | 需要什么数据 |
|------|------|------------|
| P1 | 后手优势是否存在及量级 | 同策略 P0 vs P1 各打 N 场的镜像数据 |
| P2 | 先手是否被迫更多无效行动 | 同策略镜像数据中的行动质量对比 |
| P3 | 首杀后雪崩效应的独立存在性 | 中等质量策略对弈，首杀时间的精确分析 |
| P4 | 结构性不可竞争卡组配对 | 大样本同策略数据，控制先后手 |
| P5 | 时间压力对先手是否更不利 | 同策略慢速卡组对局的平局分析 |
| P7 | 切人目的分化是否由先后手导致 | 同策略数据中的切人动机分析 |
| P8 | 支援牌投资回报时间不对称 | 同策略数据中的出牌时序分析 |

## 四、训练数据对 RL 的实际影响

### 4.1 数据中的价值信号偏差

由于当前数据是弱策略（训练模型 P0）vs 更强策略（启发式 P1），从中提取的 RL 训练信号存在以下偏差：

1. **胜负信号混淆**：大量数据中 P0（训练模型侧）败北，但 model 无法区分"策略弱"和"先手位置不利"
2. **行动偏好偏差**：训练模型从这些数据中学到的可能是"启发式策略的做法"，但这不等于"最优策略"
3. **先后手混淆**：观察值中 P0 恒为训练模型，模型可能学到错误的先后手关联

### 4.2 修正建议

1. **对称化训练数据**：每个 matchup 的 P0/P1 应交替分配训练模型和启发式策略，避免模型学到"我是先手所以我弱"的错误关联
2. **观察值包含先后手标记**：无论数据是否对称，observation 中都应包含 `isFirstPlayer` 特征
3. **评估时分离因素**：评估胜率时，应同时报告"P0胜率"和"P1胜率"，以及同策略镜像对弈的胜率
4. **增大回放采样**：每个 matchup 至少保留 5-10 场回放（而非当前的 1 场），以减少随机性对结论的影响
5. **sideA/sideB 交替**：在 self-play 配置中，应有一半的局让训练模型做 P1（后手），以平衡数据

## 五、总结

之前的 `replay-hidden-constraints-v2.md` 中基于 62 场 compact 对局得出的 P1-P9 约束，存在严重的**采样偏差**：

1. **双方策略不平等**：P0 是迭代训练模型，P1 是启发式策略，策略能力差异远大于先后手差异
2. **P0 恒为训练模型**：数据中 P0 恒为 sideA（训练模型），无法区分先后手效应和策略能力差异
3. **每 matchup 仅 1 场回放**：单场数据的随机性极大，无法得出可靠的胜率结论

**因此，P1（后手87%优势）、P2（行动质量鸿沟由先后手导致）、P7（切人分化由先后手导致）的归因不成立。**后者应在同策略镜像数据中重新验证。

**仍成立的结论包括**：P6（死亡四重惩罚，引擎规则推论）、P9（伤害阈值效应，游戏机制推论）、以及原文档 H1-H8 的全部内容。
