## 二、对局中观察到的系统性失误模式

以下模式在 62 场对局中**反复出现**，表明 baseline agent 在这些维度上存在系统性盲区。

### 失误模式 1：能量管理与爆发窗口的系统性失败

**理论预期**（framework.md §9.3.1, §14.3）：
- `E_plan`：充能增长应作为未来兑现收益的核心
- 能量从 `max_energy-1` 到 `max_energy` 时产生价值跳变
- 应在角色核心功能坍缩前完成爆发兑现

**实际对局表现**：
- 败方角色频繁积累到 2-3 能量后**在未使用爆发的情况下死亡**
- 典型案例：ShuiZhai 的 1401 三次充能到 3，但每次都因被击倒而浪费
- MoYou 的 1506 在多场对局中全程能量停留在 0/0/0——**从未使用过元素爆发**
- 胜方角色通常在 R4-R5 完成充能并成功释放爆发，立即击倒对手角色

**对应的隐藏约束**：
> **约束 H1：爆发兑现必须在角色功能坍缩窗口内完成。**  
> 充能本身不产生价值，只有在角色仍能存活到使用爆发时，充能才有效。当前 agent 将"充能"视为无条件的未来收益（`E_plan`），而忽略了充能兑现的时间窗口约束。

---

### 失误模式 2：角色功能层级与保护优先级的缺失

**理论预期**（framework.md §14.3, three-character-collapse.md）：
- 角色功能分为三层：核心功能 > 战术功能 > 残余功能
- 角色在卡组胜利路径中的重要性不同
- 失去一个角色会导致约束空间不可逆坍缩

**实际对局表现**：
- 迪希雅（ID:1309）在 HongNiu 卡组中**每场都被优先击倒**（R3-R5），Agent 未将其作为需要保护的战术功能角色
- 雷电将军（ID:1407）在 LeiHe 卡组中**平均 R2-3 即被击倒**，对手显然在集中火力但 Agent 未做应对
- 低 HP 角色（如 2301 仅 9HP）被暴露在前台承受过多伤害
- 角色间切换以**被动反应**为主（受伤后切换），而非**主动规划**（预防性切换）

**对应的隐藏约束**：
> **约束 H2：角色保护优先级应由其在卡组胜利路径中的功能层级决定，而非由当前 HP 决定。**  
> 当前 agent 的切换逻辑更接近"谁被打就换谁"，而非"谁的功能不可替代就保护谁"。迪希雅的减伤/挂火功能在前期对 HongNiu 至关重要，但 agent 将其作为可牺牲的前排。用户注：开完1次战技后迪希雅确实可以直接送掉。

---

### 失误模式 3：爆发窗口的多步规划缺失

**理论预期**（framework-missing-modules.md §D, framework.md §9.3.3）：
- `L_plan`：展开线解锁收益需要多步操作序列规划
- 高质量回合需要 turn-level 的操作序列规划（骰子分配、操作顺序）
- 同样的操作集合，不同顺序可导致完全不同的结果

**实际对局表现**：
- Agent 的操作序列看起来是**逐步贪心**，而非有计划的组合
- 未观察到"快速行动铺垫 → 战斗行动兑现"的典型组合技模式
- 胜方（尤其是 ShenXiao）展现出明确的多步爆发窗口：积累能量 → 切人上元素 → 触发反应链 → 击倒
- 败方的操作更分散：先放一个技能 → 对手反应 → 再放另一个技能，缺乏协同

**对应的隐藏约束**：
> **约束 H3：有效的伤害输出需要回合内的操作序列规划，而非独立动作的逐个执行。**  
> 回合内操作顺序影响骰子消耗、元素附着时机、行动权交替。当前 agent 缺少 turn-level planning 能力。

---

### 失误模式 4：元素反应链的有意识设计缺失

**理论预期**（framework-missing-modules.md §A, strong-coupling-and-deckbuilding.md §2）：
- 元素附着是公共状态，反应结果取决于双方策略
- 反应链（如扩散 → 后台二元反应）是应**有意识设计**的高收益操作序列
- "谁先挂元素、谁触发反应"是一个核心博弈点

**实际对局表现**：
- Agent 的元素附着使用呈现**无规划**特征——上元素但不跟进触发
- 多次观察到"上了一个元素 → 对手反而利用这个元素打出了反应增伤"
- 未观察到有意识地利用扩散的 AoE 特性打击后台角色
- ShuiBa 卡组（水系为主）虽然理论上有丰富的蒸发/冻结机会，但实际输出极低

**对应的隐藏约束**：
> **约束 H4：元素反应是一个需要主动规划的博弈过程，而非自然的附带效果。**  
> 元素附着是对双方可见的公共状态。Agent 上元素时未考虑对手可能的利用方式，也未规划自己的后续触发。

---

### 失误模式 5：骰子经济学的系统性忽视

**理论预期**（framework-missing-modules.md §B, missing-modules-guiding-questions.md §B）：
- 骰子类型价值随手牌和出战角色动态变化
- 调和 = 牺牲手牌质量换取骰子质量，是关键的经济决策
- 费用结构（同色费 vs 杂色费）直接影响操作可行性

**实际对局表现**：
- 调和使用频率在败方对局中极低，Agent 倾向于"有什么骰子就用什么"
- 未观察到针对特定操作序列的骰子预规划（如"先调和再行动"）
- 败方频繁出现"剩余骰子无法执行任何有效操作"的局面
- 骰子利用率（有效操作数 / 总骰子数）在败方明显低于胜方

**对应的隐藏约束**：
> **约束 H5：骰子分配需要在回合开始时就完成初步规划，而非逐个操作时才考虑。**  
> 骰子颜色和数量直接决定合法操作集 A(s)。缺乏骰子规划意味着 agent 可能错过需要特定颜色骰子的关键操作。

---

### 失误模式 6：对局阶段转换的无意识

**理论预期**（framework-missing-modules.md §C）：
- 对局应分为展开期 / 执行期 / 收束期
- 不同阶段策略优先级完全不同
- 阶段转换由关键事件触发（首个角色击倒、核心组件就位等）

**实际对局表现**：
- Agent 在对局前中后期的策略**无明显差异**
- 快攻型卡组（ShenXiao）的对手未能在展开期加快节奏，仍以中速策略应对
- 控制/续航型卡组（ShuiNing）的对手未能在收束期施加时间压力
- 接近 15 回合时限时，Agent 未表现出"必须终结比赛"的紧迫感（3 场 15 回合平局均属此类）

**对应的隐藏约束**：
> **约束 H6：策略应随对局阶段动态调整。**  
> 展开期应偏向 setup（铺装备、充能），执行期应偏向输出和击倒，收束期应考虑时间压力和斩杀线。当前 agent 缺乏阶段感知能力。

---

### 失误模式 7：首杀后加速雪崩的不可逆坍缩

**理论预期**（three-character-collapse.md）：
- 3→2 角色坍缩是不可逆的
- 骰子预算从 ~2-3/角色跃升至 ~3-4/角色，改变约束空间形状
- 剩余两人的最优策略与三人时完全不同

**实际对局表现**：
- 首个角色死亡后，Agent **未调整策略**以适应 2 角色约束
- 切人策略在 2 角色时仍然频繁但无目的（LeiLang 最多切换 18 次仍落败）
- 2 角色状态下未能利用增加的骰子预算执行更高费用的技能组合
- 典型模式：首杀发生在 R3-R5 → 2-3 回合内全部角色被击倒

**对应的隐藏约束**：
> **约束 H7：角色数量变化要求策略模式的根本转换，而非简单缩减。**  
> 从 3 角色到 2 角色不是"少了一个选项"，而是约束空间形状的质变。剩余角色获得更多骰子预算，但丧失了轮转灵活性和元素反应链的完整性。Agent 需要识别这一转换并调整策略。

---

### 失误模式 8：角色价值与 HP 的非线性关系未被建模

**理论预期**（framework.md §14, framework-critical-gaps.md §2.1）：
- HP 的价值是分段非线性函数，临界点不固定
- 血量低于斩杀线时风险跳变
- 低 HP 角色是否需要保护取决于其功能层级，而非绝对 HP 值

**实际对局表现**：
- Agent 的治疗行为呈现**反应式**——受伤后才治疗，而非预防性保护
- 高功能角色的低 HP（如 2 HP 的核心输出位）和低功能角色的低 HP 被同等对待
- 未观察到根据对手可能的斩杀线来判断"当前 HP 是否安全"的行为
- 3 场平局中，双方都无法有效利用 HP 优势转化为胜势

**对应的隐藏约束**：
> **约束 H8：HP 的战略价值不等于其数值，而取决于"距离功能坍缩还有多远"。**  
> 一个 3 HP 的核心输出位可能比一个 8 HP 的辅助位更需要保护。当前 agent 未能区分。

## 三、理论文档中已提出但 Agent 完全未体现的概念

以下概念在 `gitcg-theory` 文档中被详细讨论，但在 62 场对局中**完全未观察到任何运用痕迹**。

### 3.1 机会成本思维（framework.md §9.2, §9.4）

理论中定义了 `C_now`（即时机会成本）和 `C_plan`（展开机会成本）。对局中未观察到：
- 为保留关键窗口而放弃当前次优操作的行为
- "为了后续更优展开而保留骰子/手牌"的决策
- 识别"当前操作会封锁更优路径"的能力

### 3.2 信息效应（dynamic-thresholds-and-conditional-features.md §2）

理论中提出"未打出的牌也在影响博弈"。对局中未观察到：
- 基于对手已打出/调和的牌推断其手牌组成
- 通过行动选择传递（或伪装）信息意图
- 识别对手可能的威胁牌并提前规避

### 3.3 效果族分类（static-effect-meta-priors-for-rl.md §2.1）

理论中提出将卡牌效果归类为 `damage_buff_once`、`tempo_gain_now` 等效果族。对局中未观察到：
- 根据 effect family 选择操作的策略
- 区分"setup 牌"和"兑现牌"的使用时机
- 效果族之间的协同利用（如先挂元素再用增伤）

### 3.4 风险的时间尺度（framework.md §14.4）

理论中将风险分为"短期（下一次行动）"和"中期（完成本轮职责前）"。对局中未观察到：
- 评估"当前角色能否在本轮完成预定任务"的能力
- 根据风险时间尺度调整保护优先级

### 3.5 胜利路径识别（framework-missing-modules.md §E）

理论中提出不同卡组有不同的胜利路径（击倒/耗尽/碾压）。对局中未观察到：
- Agent 对自身卡组胜利路径的任何意识
- 针对不同对手卡组调整胜利路径的行为
- "原有路径不可行时切换路径"的灵活性

## 四、按影响程度排序的改进建议

| 优先级 | 约束 | 改进方向 | 预期收益 |
|--------|------|---------|---------|
| **P0** | H1: 爆发窗口约束 | 引入"充能-爆发时间窗口"特征，当角色能量接近满时提高保护优先级 | 消除能量浪费，提高关键伤害输出 |
| **P0** | H3: 多步规划 | 引入 turn-level planning，在回合开始时做 2-3 步前瞻 | 解锁组合技操作序列 |

| **P1** | H4: 反应链规划 | 引入元素反应准备度特征，主动规划附着-触发序列 | 提高伤害效率 |
| **P2** | H5: 骰子经济学 | 在 reroll 阶段引入初步回合规划，指导骰子重投选择 | 减少骰子浪费 |
| **P2** | H6: 阶段感知 | 引入对局阶段特征（展开/执行/收束），动态调整策略权重 | 适配不同阶段的最优策略 |
| **P3** | H7: 角色数量适应 | 检测角色数量变化，切换到对应的策略模式 | 减少坍缩后的加速雪崩 |
| **P3** | H8: HP 非线性价值 | 引入功能坍缩距离特征替代绝对 HP 值 | 更准确的风险评估 |

## 六、具体对局案例（供人工审阅）

### 案例 1：MoYou-vs-ShenXiao — 完全零封（5 回合，胜方 30/30 HP）

- **文件**：`MoYou-vs-ShenXiao/compact-game-0001-p1.json`
- **现象**：MoYou 的 1506 从 R1 开始每回合受伤，R2 即被击倒。三角色在 5 回合内全灭。胜方 ShenXiao 全程 10/10/10 HP 未受任何伤害。
- **理论解释**：MoYou 作为极其依赖特定反应序列（水-扩散水-冻结）的卡组（1506/1203/1106），未能规划出有效的元素反应链。Agent 缺少 H3（多步规划）和 H4（反应链规划）能力，导致完全无法组织有效进攻。
- **人工审阅要点**：MoYou 应如何在 T1-T2 规划元素附着？哪些角色应该首发？是否有更好的技能释放顺序？最常规的展开路线中，T1莫娜战技，剩余5骰子利用支援牌蓄爆用于后续回合发力；T2利用莫娜的被动速切至流浪者扩散出伤并尽可能多打伤害，最后优菈利用冻结进行残局收割。

### 案例 2：ShuiNing-vs-ShuiBa — 15 回合平局

- **文件**：`ShuiNing-vs-ShuiBa/compact-game-0001-draw.json`
- **现象**：双方大量治疗、回复，但都无法制造致命伤害。15 回合超时平局。
- **理论解释**：两个续航型卡组对局时，缺少 H6（阶段感知）的 Agent 无法在合适时机转向进攻策略。治疗优先级过高导致永远无法击倒对手。
- **人工审阅要点**：续航型卡组内战中，何时应从"保活"转向"进攻"？是否有明确的转换阈值？对手关键角色切换为出战角色、斩杀足够（伤害够高、最好能速切不会被躲）且不会导致本回合后续行动过于受限（导致被反打）。明确的转换阈值视具体角色和手牌而定。

### 案例 3：LeiHe-vs-ShenXiao — 4 回合极速溃败

- **文件**：`LeiHe-vs-ShenXiao/compact-game-0001-p1.json`
- **现象**：LeiHe 的雷电将军（1407）R2 即被击倒，随后在 4 回合内全灭。胜方 ShenXiao 全程未受伤。
- **理论解释**：LeiHe 缺少 H2（功能层级保护）——雷电将军是该卡组的核心充能/爆发引擎，但 Agent 将其暴露在前台承受致命伤害。缺少 H1（爆发窗口）——角色未能在存活期间完成充能和爆发。
- **人工审阅要点**：雷电将军是否应作为首发角色？如果首发，应如何规划保护（支援区减伤、切换规避等）？正常情况下都是雷电将军首发，但召唤召唤物后不一定要站场至开出元素爆发，可以直接切换至队友走另一条展开路线。

### 案例 4：HongNiu-vs-ShenXiao — HongNiu 唯一胜利

- **文件**：`HongNiu-vs-ShenXiao/compact-game-0001-p0.json`
- **现象**：HongNiu 胜出。关键特征：一斗（1605）**全程保持在 10 HP 直到 R8**，从未受伤。迪希雅（1309）被牺牲但完成了减伤/挂火的战术功能。
- **理论解释**：这是罕见的"正确"运用 H2（功能层级保护）的对局。一斗作为核心输出被保护在后台，迪希雅承担牺牲角色。然而这可能只是 baseline 随机行为的结果而非有意识策略。
- **人工审阅要点**：这一局的胜利是偶然还是有策略逻辑的？如果是偶然，如何将这种保护模式系统化？应该是偶然事件，实际最好是迪希雅召唤召唤物后切换一斗开始出伤、充能。正确模式的固化尚未有方案。

## 七、总结

baseline agent 在 62 场对局中暴露的核心问题，可以用理论框架中的三个概念概括：

1. **缺少 `G_plan`（未来展开收益）的评估能力** — Agent 只看即时收益（`G_now`），不规划未来 2-3 步的组合收益
2. **缺少 `R(s,a)`（风险）的建模能力** — Agent 不评估"这一步会让关键角色功能坍缩吗"
3. **缺少 `C_plan`（展开机会成本）的感知能力** — Agent 不判断"这一步是否在浪费更好的展开路径"

这三个缺失共同导致了：能量浪费、核心角色无保护死亡、操作无协同、元素反应无规划、骰子利用低效。

理论上，这些约束在 `gitcg-theory` 文档中已被充分讨论。将其转化为可计算的 derived features 和 shaping rewards，是改进 baseline agent 性能的关键路径。
