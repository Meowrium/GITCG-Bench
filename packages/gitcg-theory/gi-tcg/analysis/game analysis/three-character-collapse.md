# 三角色体系的不可逆坍缩

## 现象

三个角色的联动、排轴，与两个角色、一个角色下的情形截然不同。拿走一个角色后，剩余角色构成的战术会自发收敛向截然不同的组合结果，且这种"坍缩"不可逆——加回被移除的角色，剩余两人的行为模式不会恢复原状。

## 初步分析：为什么会坍缩

### 1. 骰子作为硬约束

每回合固定 8 骰子是整个体系的边界条件。三个角色时，8 骰子需要分配给：
- 切人消耗（1 骰子）
- 主行动（3-5 骰子）
- 可能的辅助行动（2-3 骰子）

这意味着**三角色时，任何单一角色的每回合预算被压缩到约 2-3 骰子**。角色之间被迫形成分工——不可能每个人都在做主 C 的事。

两个角色时，每人每回合预算跃升至 3-4 骰子。这不是线性变化——当预算从"必须精打细算"跳到"可以完整执行一个技能"时，角色的**可用选项空间发生了质变**。原本因骰子不足而被抑制的技能路径突然变得可行。

### 2. 角色功能在约束下的涌现

关键洞察：角色的"定位"不是固定的，而是**被约束塑造出来的**。

三个角色时：
- 香菱只能做后台——前台站不住且浪费骰子
- 行秋只能做副 C——前台没普攻收益
- 迪卢克被迫做纯前台——后台无产出

三个角色形成一个**功能三角**，每个角色被骰子约束压入自己的生态位。

移除一个角色后（比如移除迪卢克），剩香菱+行秋：
- 两人共享前台位置，轮流输出
- 香菱不再"只能后台"——她现在有足够骰子在前台放 E 挂火
- 行秋也不再"只能副 C"——他的雨帘剑在前台有减伤意义
- 两人的技能选择从"配合主 C"收敛为"两人之间的最优轮换"

**角色没有变，技能没有变，变的是约束条件下的最优解。**

### 3. 不可逆的来源

不可逆性来自**学习/适应的非对称性**：

当三角色体系运转时，剩余两人的行为模式是基于"有第三个人兜底"来优化的。移除一人后，他们重新优化出了新的双人协作模式。这个新模式是**全局最优解**（在双人约束下）。

加回第三人时，三人并不会恢复原状，因为：
- 新的双人模式已经被锁定为"默认行为"
- 重新引入第三人需要重新探索三人空间——这是一个更大的搜索空间
- 对手也在适应——对手已经学会了针对双人模式的打法

这类似于**生态位释放**（ecological release）：移除一个物种后，剩余物种会扩展自己的生态位；重新引入时，它们不会自动退回原来的范围。

### 4. 数学直觉：约束维度与解空间

从组合角度看：

```
单人：技能序列搜索空间 = S^n（S = 可选技能数，n = 回合数）
双人：每个位置独立选择，但共享骰子 → (S²)^n 但受骰子约束裁剪
三人：(S³)^n 但受更紧的骰子约束裁剪
```

骰子约束裁剪三人空间**远比**裁剪双人空间激进。三人时，每回合的有效行动组合（满足骰子约束的）可能只有 10-20 种；双人时可能膨胀到 50-100 种。

这意味着：
- **三人的最优策略更尖锐**——在狭窄空间里，某一组合明显优于其他
- **双人的最优策略更平坦**——更多组合差不多好，但它们和三人最优策略方向不同
- 从三人切换到双人，不是"去掉一个维度"，而是"约束空间形状完全改变"

### 5. 更深层的原因：元素反应是三元关系

七圣召唤的元素反应系统天然偏好**三元结构**：
- 反应 = 元素A + 元素B（二元）
- 但维持反应节奏需要：挂元素者 → 触发者 → 挂元素者（轮换，至少三方参与才高效）

三人时可以形成 A→B→C→A 的反应链。两人时这个链被迫断成 A→B→A，节奏变慢且更难维持连续反应。

移除一人后，反应链断裂，整个队伍的**收益函数形状改变**，最优行为自然收敛到新的模式。

## 开放问题

1. **临界点**：是否存在一个"最小 viable 队伍规模"？单人能否通过特定卡牌组合模拟出类似三人的效果？可以（召唤物、装备等是否充当了"虚拟第三人"）

2. **坍缩的速度**：移除角色后，剩余角色需要多少回合才能收敛到新模式？瞬间重算（在 AI 搜索中这等于——beam search 在新的约束下多少步收敛到新的最优路径）

3. **通用性**：这个现象在其他有资源约束的卡牌游戏中是否也存在？对比：炉石（无共享资源，坍缩可能不存在）vs 万智牌（地费用共享，可能存在类似效应）

4. **对 AI 设计的启示**：如果三人→双人的坍缩不可逆，那么 AI 在训练/搜索时是否需要分别为不同人数的队伍维护独立的策略网络？还是说应该始终以三人为基准训练，让双人策略自然涌现？
