# Generative Agents: Interactive Simulacra of Human Behavior

- **arXiv ID**: [2304.03442](https://arxiv.org/abs/2304.03442)
- **Authors**: Joon Sung Park, Joseph C. O'Brien, Carrie J. Cai, Meredith Ringel Morris, Percy Liang, Michael S. Bernstein (Stanford, Google)
- **Date**: 2023-04-07
- **Venue**: UIST 2023 (Best Paper)
- **Citations**: Very High (landmark paper)
- **Relevance Score**: ⭐⭐⭐⭐ (4/5 — 记忆架构的经典三层设计)

## Summary

提出生成式 agent——模拟可信人类行为的计算软件 agent。架构将 LLM 扩展为：(1) **Memory Stream**：用自然语言存储 agent 的完整经验记录；(2) **Reflection**：随时间推移将记忆合成为更高层的反思；(3) **Planning**：动态检索记忆来规划行动。Agent 在模拟小镇中自主生活——醒来、做早餐、上班、社交，展现出 emergent social behaviors。

## Key Contributions

- **三层记忆架构**：Memory Stream（原始事件日志）→ Reflection（定期提炼高层 insight）→ Planning（基于反思生成日计划）
- **记忆检索**：recency + relevance + importance 三因子打分检索
- **Interaction**：agent 之间的自然语言互动产生 emergent 行为
- **Believability**：评估框架不只是 task completion，还包括行为可信度

## Connection to Our Work

- **直接映射到 strategy_store**：你的 `strategy_store` 已经做了持久化，缺的是自动 Reflection——从对局日志中定期提炼 insight。三层对应：Memory Stream = gameLog.json → Reflection = Critic 产出 cross_game_lessons → Planning = PlanV2 下局生成时参考 lessons。
- **记忆检索三因子**：当前 strategy_store 只有 key-based lookup（`p0_anchor`）。多局后积累的 lessons 需要 relevance 检索——「当前对手是双冰卡组 → 检索历史上对双冰卡组的 lessons」。
- **Believability 作为 eval 维度**：超越 win rate——AI 的对局行为是否像人类？是否在合适时机做出了合理的 panic switch？这可以是对局 replay 的质量评估指标。

## Critical Assessment

**Strengths**: 记忆架构经典、三层设计清晰可复用、自然语言记忆可解释。
**Weaknesses**: 非游戏场景；Reflection 的触发是时间驱动的（不适用回合制）；记忆检索开销随记忆增长（需要 relevance scoring）。
**Reproducibility**: 架构清晰但工程量大。
