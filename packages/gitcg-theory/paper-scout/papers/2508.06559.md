# Solving Pasur Using GPU-Accelerated Counterfactual Regret Minimization
- arXiv ID: 2508.06559
- Authors: Sina Baghal
- Date: 2025-08-06
- Relevance Score: ⭐⭐⭐⭐⭐

## Summary
This paper introduces a CUDA-accelerated framework for computing near-Nash equilibria in Pasur, a fishing card game similar to Cassino and Scopa, using Counterfactual Regret Minimization (CFR). Pasur presents challenges due to its intricate rules and large game tree (>10^9 nodes). The approach decomposes the game tree into card states and inherited scores, then uses a backward round-by-round training strategy. After computing equilibrium strategies, a tree-based model is trained to predict strategies for gameplay, and large-scale self-play (10,000 games per matchup) is used to evaluate deck fairness. The GPU implementation manages memory efficiently through PyTorch CUDA tensors and stores only essential strategy values and node connections.

## Key Contributions
- First complete CFR-based solution for a fishing card game with >10^9 node game tree
- Novel game tree decomposition: separates card states from accumulated scores via an "Unfolding Process"
- Round-by-round backward training strategy: starts from final round and propagates utilities to earlier stages
- Tree-based model distilled from equilibrium strategies for real-time gameplay
- GPU-accelerated self-play framework evaluating 10,000 games per matchup for deck fairness analysis

## Connection to Our Work
- **Game tree decomposition**: The round-by-round decomposition mirrors how GI TCG games could be structured — each round is a subgame. The backward training strategy (solving end-game first, then propagating to earlier rounds) is directly applicable.
- **CFR → tree distillation**: The approach of computing equilibrium via CFR then distilling to a lightweight tree model for gameplay is relevant — we could compute CFR subgame solutions for GI TCG endgame states and distill them into our MCTS value network.
- **GPU acceleration**: The CUDA memory management patterns are relevant for scaling CFR or MCTS on GPU for GI TCG.
- **Deck evaluation**: The deck fairness framework is conceptually similar to deck prior evaluation we want to do with LLM.

## Critical Assessment
**Strengths**: Comprehensive end-to-end framework from CFR computation to gameplay model. Practical memory management for large game trees. Clear methodology with implementation snippets.

**Weaknesses**: Single-game focus (Pasur); unclear how well the decomposition generalizes to games with different structures. Single author — limited peer review context.

**Reproducibility**: Good — includes implementation snippets. But requires specific GPU hardware and game-specific rule encoding.
