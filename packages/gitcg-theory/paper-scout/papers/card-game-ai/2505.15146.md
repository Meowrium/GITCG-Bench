# lmgame-Bench: How Good are LLMs at Playing Games?

- **arXiv ID**: [2505.15146](https://arxiv.org/abs/2505.15146)
- **Authors**: Lanxiang Hu, Mingjia Huo, Yuxuan Zhang, Haoyang Yu, Eric P. Xing, Ion Stoica, Tajana Rosing, Haojian Jin, Hao Zhang
- **Date**: 2025-05-21
- **Categories**: cs.AI
- **PDF**: https://arxiv.org/pdf/2505.15146

---

## 核心内容

评估 LLM 打游戏的 benchmark。三个发现：
1. **视觉感知不可靠**: 直接丢 LLM 进游戏行不通
2. **Prompt 敏感**: 不同 prompt 表现差异大
3. **数据污染风险**: 训练数据可能见过游戏内容

解决: Gym-style API + 轻量感知/记忆 scaffold + 去污染设计。

跨 13 个模型测试，每个游戏测试不同的能力组合。有趣发现：**在单个游戏上做 RL 可以迁移到未见过的游戏和外部规划任务。**
