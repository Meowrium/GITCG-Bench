# Causal Reinforcement Learning for Complex Card Games: A Magic The Gathering Benchmark

- **arXiv ID**: [2605.06066](https://arxiv.org/abs/2605.06066)
- **Authors**: Cristiano da Costa Cunha, Ajmal Mian, Tim French, Wei Liu
- **Date**: 2026-05-07
- **Venue**: arXiv preprint (cs.LG, cs.AI)
- **Citations**: 0 (new paper, Semantic Scholar)
- **Relevance Score**: ⭐⭐⭐⭐⭐ (5/5)

## Summary

Introduces **MTG-Causal-RL**, a Gymnasium benchmark built on Magic: The Gathering that combines sequential decision-making, hidden information, large masked action spaces (3,077-dim observation, 478 actions), and explicit causal structure via a hand-specified Structural Causal Model (SCM). Proposes **CGFA-PPO** (Causal Graph-Factored Advantage PPO) that uses SCM parents of win probability as factor-aligned critic targets. Benchmarks include masked PPO, causal-world-model PPO, and heuristic baselines under statistical rigor (paired seeds, bootstrap CIs, Holm-Bonferroni correction).

## Key Contributions

- First benchmark to unify causal RL, hidden information, and large masked action spaces in a complex card game
- SCM-grounded evaluation: per-factor calibration trajectories, cross-archetype transfer gaps, policy auditability
- Open-source release of benchmark, baselines, and evaluation protocol
- Shows that scalar win rate alone misses diagnostic structure visible through causal credit assignment

## Connection to Our Work

- **Direct card game domain overlap**: MTG's complexity (deck construction, hidden info, sequential play) mirrors GI TCG's challenges. The 478-action space with masking is analogous to GI TCG's action filtering.
- **Causal structure → CGT bridge**: The SCM approach to modeling strategic variables is conceptually aligned with Combinatorial Game Theory's decomposition of game states. Could inform how we structure deck-prior features.
- **Benchmark design methodology**: The statistical protocol (paired seeds, bootstrap CIs, Holm-Bonferroni) is a gold standard we should adopt for GI TCG agent evaluation.
- **Transfer learning**: Cross-archetype transfer evaluation directly maps to cross-deck generalization, a core challenge for our LLM deck prior.

## Critical Assessment

**Strengths**: Rigorous methodology; clean separation of causal structure from policy; open-source release enables reproduction.  
**Weaknesses**: CGFA-PPO only matches masked PPO (no causal benefit yet shown for win rate); SCM is hand-specified (not learned); MTG is a subset of the full game.  
**Reproducibility**: High — Gymnasium environment, open-source code, documented statistical protocol. The benchmark is designed for others to build on.
